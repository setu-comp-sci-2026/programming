## Exercise 2 — Safe product code

Create `exercise_02_product_code.py`. Ask for a product code that must be a whole number between **100 and 999**. Use a Boolean-controlled loop, `try`/`except ValueError`, and an `if` range check. Test `abc`, `99`, `1000`, `205`.

## Exercise 3 — Safe rating function

Create `get_rating()` that repeatedly asks for a whole number between **1 and 5** and returns it. Call the function and display the returned value. Test `five`, `0`, `6`, `3`.

## Exercise 4 — Use `else` and `finally`

Ask for an integer. Print its square in `else` when conversion succeeds, print a helpful message in `except ValueError` when it fails, and print `Attempt complete` in `finally`. Test `7` and `seven`.

## Exercise 5 — Load student data safely
