# else, finally and exception families

Create `08_else_finally.py`.

## 1. `else` runs when no exception occurs

```python
try:
    number = int(input("Number: "))
except ValueError:
    print("Not a whole number")
else:
    print("Double:", number * 2)
```

Test `5` and `five`. Why is the calculation in `else` rather than `except`?

## 2. `finally` runs either way

```python
try:
    number = int(input("Number: "))
except ValueError:
    print("Invalid number")
finally:
    print("Input attempt finished")
```

Test both valid and invalid input. Which message always appears?

## 3. Catch a specific error first

Create `09_file_errors.py`:

```python
try:
    with open("missing.txt", "r", encoding="utf-8") as file:
        print(file.read())
except FileNotFoundError:
    print("The file does not exist")
except PermissionError:
    print("You do not have permission to read this file")
except OSError:
    print("Another operating system error occurred")
```

`FileNotFoundError` and `PermissionError` are specific kinds of `OSError`. Put specific handlers before general handlers so they can respond differently.
