# Week 8 Monday — Errors and Exception Handling

**Python skills:** syntax errors · runtime errors · logic errors · tracebacks · `try` / `except` · validation · `else` / `finally` · JSON file errors

## Learning outcomes

By the end of the lab, you should be able to:

- Identify syntax, runtime and logic errors.
- Read a traceback and locate the line where an exception occurred.
- Catch a specific exception using `try` and `except`.
- Combine input validation with exception handling and a Boolean-controlled loop.
- Use `else` and `finally` appropriately.
- Handle missing or damaged JSON files without losing existing data.
