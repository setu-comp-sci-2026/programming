# Errors and tracebacks

Create `01_errors.py`.

## 1. Syntax error

Type and run this code **exactly as shown**:

```python
mark = 55
if mark >= 40
    print("Pass")
```

Python cannot run it. Read the message and identify the missing `:`. Fix it and run again.

## 2. Runtime error

Create `02_runtime.py`:

```python
product_code = int(input("Product code: "))
print("You entered:", product_code)
```

Test `123` and then `iPhone11`. What exception name appears? Which line caused it?

## 3. Logic error

Create `03_logic.py`:

```python
mark = 75
if mark < 40:
    print("Pass")
else:
    print("Fail")
```

The code runs but gives the wrong result. Fix the condition. Test marks `39`, `40`, and `75`.

## 4. Read the traceback

Create `04_traceback.py`:

```python
dogs = [{"name": "Buddy"}]
print(dogs[1]["age"])
```

**Predict:** Does `IndexError` or `KeyError` happen first? Run the program to check. Then change `[1]` to `[0]` and run again. Why has the exception changed?
