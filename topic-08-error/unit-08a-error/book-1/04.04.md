# Saving and loading JSON safely

Create `10_json_errors.py`.

## 1. Save a list of dictionaries

```python
import json

products = [
    {"code": 101, "name": "Mouse"},
    {"code": 102, "name": "Keyboard"}
]

with open("products.json", "w", encoding="utf-8") as file:
    json.dump(products, file, indent=4)
```

Run this code. Open `products.json` and inspect the data.

## 2. Handle errors when saving

Create `11_save_dogs.py`:

```python
import json


def save_dogs(dogs):
    try:
        with open("dogs.json", "w", encoding="utf-8") as file:
            json.dump(dogs, file, indent=4)
    except OSError as error:
        print("Could not save dogs:", error)
        return False
    return True


dogs = [{"name": "Buddy", "age": 4}]
if save_dogs(dogs):
    print("Saved successfully")
```

**Question:** Why do we print the success message only if the function returns `True`?

## 3. Handle a missing file

Create `12_load_dogs.py`:

```python
import json


def load_dogs():
    try:
        with open("dogs.json", "r", encoding="utf-8") as file:
            return json.load(file)
    except FileNotFoundError:
        print("No saved data yet")
        return []


dogs = load_dogs()
print(dogs)
```

Run this with and without `dogs.json`. A missing file can mean a new project with no saved records yet.

## 4. Handle damaged JSON differently

Extend `load_dogs()` by adding this **second** handler after `FileNotFoundError`:

```python
    except json.JSONDecodeError:
        print("Saved data is not valid JSON")
        return None
```

To test, open `dogs.json`, remove a comma or closing brace, save, and rerun. **Back up the valid file before damaging it.**

**Important:** `[]` means no records were found because the file is missing; `None` means the saved data could not be loaded safely. Do not automatically overwrite damaged data with an empty list.
