# Handle exceptions in the calling code

Create `13_average.py`.

## 1. Catch an exception in the caller

```python
def average(total, count):
    return total / count


try:
    result = average(20, 0)
    print("Average:", result)
except ZeroDivisionError:
    print("Cannot calculate an average when count is zero")
```

The exception begins inside `average()`, but the caller handles it. This is called **exception propagation**.

## 2. Validate first when possible

```python
def average(total, count):
    return total / count


count = 0
if count > 0:
    print("Average:", average(20, count))
else:
    print("Count must be greater than zero")
```

For this simple example, the range check prevents division by zero, so an additional `try`/`except` is not necessary.
