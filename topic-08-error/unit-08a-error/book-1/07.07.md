## Challenge 1 — Reusable whole-number input

Write `get_int_in_range(prompt, minimum, maximum)` using a Boolean-controlled loop. It must reject non-integers and out-of-range values, and return a valid integer. Call it for a dog age (`0`–`25`) and a rating (`1`–`5`).

## Challenge 2 — Product records with safe persistence

Create a list of product dictionaries containing `code`, `name`, and `price`. Write `save_products(products)` returning `True` or `False`, and `load_products()` returning a list, `[]` if missing, or `None` if the file is damaged or inaccessible. Show a success message only after saving succeeds.

## Challenge 3 — Protect existing data

Extend Challenge 2 so the program **does not save** if `load_products()` returns `None`. Explain why returning an empty list for damaged JSON would be dangerous.

## Challenge 5 — Simple menu with recovery

Create a small menu for a list of dog records: `1. View`, `2. Add`, `3. Save`, `4. Exit`. Use your reusable input function to validate the menu choice. Handle errors when saving to JSON. Avoid `while True`; use a Boolean variable to control the menu loop.
