# try, except and validation

Create `05_try_except.py`.

## 1. Handle an invalid product code

```python
try:
    product_code = int(input("Product code: "))
    print("You entered:", product_code)
except ValueError:
    print("Please enter a whole number")
```

Test `101` and `mouse`. Notice that the program displays a useful message instead of an unhandled traceback.

## 2. Validation is not the same as exception handling

Create `06_dog_age.py`:

```python
valid_age = False

while not valid_age:
    try:
        age = int(input("Dog age (0–25): "))

        if 0 <= age <= 25:
            valid_age = True
        else:
            print("Age must be 0 to 25")

    except ValueError:
        print("Enter a whole number")

print("Accepted:", age)
```

Test in this order: `abc`, `-1`, `26`, `4`.

**Discuss:** Which inputs cause `ValueError`? Which inputs are valid integers but fail the age-range check?

## 3. Turn it into a function

Create `07_valid_age_function.py`:

```python
def get_valid_age():
    valid_age = False

    while not valid_age:
        try:
            age = int(input("Age (0–25): "))
            if 0 <= age <= 25:
                valid_age = True
            else:
                print("Out of range")
        except ValueError:
            print("Whole numbers only")

    return age


dog_age = get_valid_age()
print("Accepted:", dog_age)
```

**Question:** Why is `return age` after the loop? Can you move it into the `if`? If you do, which lines become unnecessary?
