# 07 — Challenges

These are more independent tasks. Attempt them before opening the solutions.

## Challenge 1 — Reusable marks module
Create `marks.py` containing:
- `average(marks)` — returns the average of a list of marks;
- `count_passes(marks)` — returns how many marks are **40 or above**.

Create `main.py` and test with `[35, 40, 62, 78, 39]`. Expected average: `50.8`; expected passes: `3`. Set a breakpoint inside `count_passes` and step through the loop.

## Challenge 2 — Make a robust calculator
Extend `calculator.py` with `divide(a, b)`. In `main.py`, ask the user for two numbers and handle `ValueError` and `ZeroDivisionError` appropriately. Decide which file should be responsible for displaying user-friendly messages. Explain your choice.

## Challenge 3 — Split a JSON program into modules
Create `storage.py` with `save_student(student, filename)` and `load_student(filename)` using `json.dump()` and `json.load()`. Create `main.py` to save a dictionary such as `{"name": "Alex", "mark": 78}` and then load it. Test what happens if you change the filename to one that does not exist. **Extension:** catch `FileNotFoundError` in `main.py`.

## Challenge 4 — Find the hidden import problem
Create `helper.py` containing:

```python
print("Starting helper...")

def double(number):
    return number * 2
```

Import it from `main.py` and call `double(5)`. Explain why `Starting helper...` appears. Change the module so the message appears only when `helper.py` is run directly.

## Challenge 5 — Diagnose three faults
A student has these files:

```text
ShopProject/
    main.py
    price_tools.py
```

`price_tools.py`:

```python
def final_price(price, discount):
    saving = price * discount / 100
    return price + saving
```

`main.py`:

```python
import price_tool

print(price_tool.final_price(100, 10))
```

Find and correct the **module-name mistake** and the **logic error**. Then change the call to `price_tools.final_cost(100, 10)` and explain the **third** problem. For each, identify whether the program raises an exception or produces a wrong answer.
