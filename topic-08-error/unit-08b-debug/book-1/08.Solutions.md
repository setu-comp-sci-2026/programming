## Code from Class — key answers
- `random.randint(1, 20)` produces integers from **1 through 20**, inclusive.
- `json.dump()` uses a function inside the imported `json` module.
- `sqrt(-1)` raises `ValueError` for `math.sqrt`.
- Calling `sqrt(16)` after only `import math` raises `NameError`; use `math.sqrt(16)`.
- `import calculater` raises `ModuleNotFoundError` when only `calculator.py` exists.
- Calling a missing `calculator.subtract()` raises `AttributeError`.
- A 20% discount on €50 should be €40; the faulty code prints €60.
- In the greetings example, the order is: `Module is loading`, `Main program is starting`, `Hello!`.
- A module's top-level test guarded by `if __name__ == "__main__":` runs when the module is executed directly, not when imported.

## Challenge 1
`marks.py`:
```python
def average(marks):
    return sum(marks) / len(marks)

def count_passes(marks):
    passes = 0
    for mark in marks:
        if mark >= 40:
            passes += 1
    return passes
```
`main.py`:
```python
import marks

results = [35, 40, 62, 78, 39]
print(marks.average(results))      # 50.8
print(marks.count_passes(results)) # 3
```

## Challenge 3
`storage.py`:
```python
import json

def save_student(student, filename):
    with open(filename, "w") as file:
        json.dump(student, file, indent=4)

def load_student(filename):
    with open(filename, "r") as file:
        return json.load(file)
```
`main.py`:
```python
import storage

student = {"name": "Alex", "mark": 78}
storage.save_student(student, "student.json")
try:
    loaded = storage.load_student("student.json")
    print(loaded)
except FileNotFoundError:
    print("Student file not found")
```
Change the filename in the **load** call to `missing.json` to test the handler.
