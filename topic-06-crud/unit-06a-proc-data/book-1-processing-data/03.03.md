## 6. Searching for Data
```python
search_id = int(input("Enter student ID: "))
found = False

for student in students:
    if student["id"] == search_id:
        print("Student found:")
        print(student["name"], student["mark"])
        found = True

if found == False:
    print("Student not found")
```

Test an existing ID, first/last ID, and a missing ID. Explain why `found` is useful.

## 7. Put the Search in a Function
```python
def find_student(students, search_id):
    for student in students:
        if student["id"] == search_id:
            return student
    return None
```

Test it:

```python
student = find_student(students, 103)

if student is not None:
    print(student["name"], student["mark"])
else:
    print("Student not found")
```

**Think:** Why is returning the student more useful than printing it inside the function?
