# CRUD Challenges

## Challenge 1 – Search by Name
Write `find_student_by_name(students, search_name)`. Return the matching student or `None`. Ignore case.

## Challenge 2 – Best Student
Write `find_highest_student(students)` and return the **student dictionary**, not just the mark.

## Challenge 3 – Analyse the Results
Write `display_summary(students)` to display number of students, passes, fails, average and highest mark. Reuse functions where possible.


## Before You Finish
Make sure you can explain list-of-dictionaries, loop variables, selection inside iteration, counters, accumulators, returning a record, and CRUD.
