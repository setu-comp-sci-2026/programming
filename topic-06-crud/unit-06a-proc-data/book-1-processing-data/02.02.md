# Student Example 1

## 1. Getting Started
Create `WorkingWithData` and a file `students.py`.

```python
students = [
    {"id": 101, "name": "Mary", "mark": 72},
    {"id": 102, "name": "John", "mark": 38},
    {"id": 103, "name": "Sarah", "mark": 55},
    {"id": 104, "name": "Adam", "mark": 81},
    {"id": 105, "name": "Niamh", "mark": 40}
]
```

Identify the list, one dictionary, the keys, and the values belonging to one student.

## 2. Reading the Records
```python
for student in students:
    print(student["name"], student["mark"])
```

**Think:** What does `student` refer to on each pass? Modify the output to include the ID.

## 3. Selection Inside a Loop
```python
for student in students:
    if student["mark"] >= 40:
        print(student["name"], "- Pass")
    else:
        print(student["name"], "- Fail")
```

### Exercise 1 – Distinction
Add a `Distinction` result for marks of 70 or higher. The possible results should be Distinction, Pass and Fail.

## 4. Counting Records
```python
passes = 0

for student in students:
    if student["mark"] >= 40:
        passes = passes + 1

print("Number of passes:", passes)
```
