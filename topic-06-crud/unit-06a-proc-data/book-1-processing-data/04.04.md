# Student Example CRUD


## 10. Introducing CRUD

| Operation | Meaning | Example |
| --- | --- | --- |
| **Create** | Add new data | Add a student |
| **Read** | View/find data | Display/search |
| **Update** | Change data | Change a mark |
| **Delete** | Remove data | Remove a student |

You have already implemented **Read**.
