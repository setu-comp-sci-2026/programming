```python
    {"id": 3, "name": "Milo", "breed": "Spaniel", "age": 6}
]
```

Write two functions:

- `display_dogs(dogs)` — display every dog.
```python
def display_dogs(dogs):
    for dog in dogs:
        print(dog["id"], dog["name"], dog["breed"], dog["age"])
```

- `find_dog(dogs, dog_id)` — return the matching dictionary or `None`.

```python
def find_dog(dogs, dog_id):
    for dog in dogs:
        if dog["id"] == dog_id:
            return dog
    return None
```
