**Focus:** representing expert knowledge with lists and dictionaries and applying CRUD to questions.

## Our project for the rest of the module

Imagine a computer won't turn on. A technician might ask:

- Does the computer turn on?
- Is the power cable connected?
- Is the power indicator light on?

Based on the answers, they might recommend checking the power supply.

We will gradually create a **rule-based expert system** that asks questions and recommends possible solutions. It is not a machine-learning system: **we write the rules it follows**.

**This week:** store and manage questions, recommendations and simple rules. We are **not** building the full decision engine yet.

## Core 6 — Store a simple rule

A rule connects an answer to a recommendation:

```python
rules = [
    {
        "id": 1,
        "question_id": 1,
        "expected_answer": "no",
        "recommendation_id": 1
    }
]
```

We can read this as:

> IF the answer to question 1 is "no", THEN recommend item 1.

1. Print the rule ID.
2. Print the expected answer.
3. Print the recommendation ID.
4. Add a second rule dictionary of your own.

**Important:** This is a deliberately simple rule with **one condition**. A real troubleshooting decision may depend on **several answers**. We'll develop that later.
