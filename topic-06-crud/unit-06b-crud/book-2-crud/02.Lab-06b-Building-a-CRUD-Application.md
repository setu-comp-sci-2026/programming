## 3. READ – Find One Dog
```python
def find_dog(dogs, dog_id):
    for dog in dogs:
        if dog["id"] == dog_id:
            return dog
    return None
```

Test both an existing and missing ID.

## 4. CREATE – Add a Dog
```python
def add_dog(dogs):
    dog_id = int(input("ID: "))
    name = input("Name: ")
    breed = input("Breed: ")
    age = int(input("Age: "))

    dog = {
        "id": dog_id,
        "name": name,
        "breed": breed,
        "age": age
    }

    dogs.append(dog)
    print("Dog added")
```

### Exercise 2 – Prevent Duplicate IDs
Use `find_dog()` before adding. Do not add a dog if its ID already exists.

## 5. UPDATE – Change a Dog
```python
def update_dog(dogs):
    dog_id = int(input("Dog ID: "))
    dog = find_dog(dogs, dog_id)

    if dog is not None:
        dog["age"] = int(input("New age: "))
        print("Dog updated")
    else:
        print("Dog not found")
```

### Exercise 3 – Update More Information
Let the user choose to change name, breed or age.

## 6. DELETE – Remove a Dog
```python
def delete_dog(dogs):
    dog_id = int(input("Dog ID: "))
    dog = find_dog(dogs, dog_id)

    if dog is not None:
        dogs.remove(dog)
        print("Dog deleted")
    else:
        print("Dog not found")
```

### Exercise 4 – Confirm Before Deleting
Display the dog's name and ask `Delete Buddy? (yes/no):`. Delete only if the answer is `yes`.

## 7. Build the Menu
```python
choice = ""

while choice != "0":
    print()
    print("DOG DAY CARE MANAGER")
    print("1. Add dog")
    print("2. View dogs")
    print("3. Update dog")
    print("4. Delete dog")
    print("0. Exit")

    choice = input("Choose an option: ")

    if choice == "1":
        add_dog(dogs)
    elif choice == "2":
        display_dogs(dogs)
    elif choice == "3":
        update_dog(dogs)
    elif choice == "4":
        delete_dog(dogs)
    elif choice != "0":
        print("Invalid option")
```
