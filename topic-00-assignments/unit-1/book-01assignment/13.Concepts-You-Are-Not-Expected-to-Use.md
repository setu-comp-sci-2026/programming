# 13. Concepts You Are Not Expected to Use

At this stage of the module, you are not expected to use:

- lists
- dictionaries
- loops
- classes
- objects
- file handling
- external Python libraries

You will learn these topics later.

Using more advanced programming features will not automatically receive additional marks.  In fact, for this assignment we ask that you **DO NOT** use more advanced features

The focus of this assignment is your understanding of the concepts covered so far.
