# Code Quality

Your code should be readable and clearly structured.

You should:

- use meaningful variable names
- use meaningful function names
- indent your code correctly
- leave suitable spacing between sections
- avoid unnecessary repetition
- include short comments where they improve understanding

For example:

```python
customer_age = int(input("Enter your age: "))

```

is preferable to:

```python
x = int(input("Age: "))

```
