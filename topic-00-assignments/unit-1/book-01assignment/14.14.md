# Use of AI Tools

AI tools can be useful for learning programming.

You may use AI tools to:

- help explain a programming concept
- help understand an error message
- suggest approaches to solving a problem
- help you debug code that you have written

However, the program you submit must represent your own understanding.

You are responsible for every line of code that you submit.

You must be able to:

- explain your code
- explain the decisions made in your program
- describe how your functions work
- demonstrate your test cases
- make a small modification to your program during the assignment discussion

Submitting code generated by another person or by an AI tool that you cannot explain or modify may result in marks being withheld and will be dealt with under the University's academic integrity procedures.
