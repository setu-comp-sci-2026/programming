# Why This Matters for AI

Your **Make My Decision!** program is a simple example of an idea that has played an important role in the history of Artificial Intelligence.

## Rule-Based AI

Before modern machine learning and generative AI systems became common, an important approach to Artificial Intelligence was **rule-based AI**.

In a rule-based system, programmers and subject experts explicitly describe the rules that the computer should follow.

For example:

```text
IF the weather is sunny
AND the user has at least 3 hours available
THEN recommend going for a hike
```

This is very similar to the selection statements you are learning in Python:

```python
if weather == "sunny" and hours_available >= 3:
    recommendation = "Go for a hike"
```

The computer is using information together with a set of rules to make a decision.

---

# Expert Systems

One particularly important type of rule-based AI is an **Expert System**.

Expert systems were designed to capture some of the knowledge and decision-making processes of a human expert.

For example, an expert system might help with:

- diagnosing a computer problem
- recommending a suitable product
- identifying a plant
- troubleshooting equipment
- providing financial or business advice
- supporting technical decisions

The system could contain many rules such as:

```text
IF symptom A is present
AND symptom B is present
THEN suggest possible problem X
```

The rules might become very large and complex, but the basic idea is something you already understand:

> **Use information to make a decision.**

---

# Rules + Data → Decision

A traditional rule-based system can be represented very simply as:

```text
       RULES
         +
    INPUT DATA
         ↓
      DECISION
```

In your assignment:

```text
   YOUR DECISION RULES
           +
      USER ANSWERS
           ↓
     RECOMMENDATION
```

You are therefore creating a small **rule-based decision system**.

---

# How Is This Different from Modern AI?

Modern Artificial Intelligence systems often use **Machine Learning**.

Instead of a programmer writing every decision rule, a machine-learning system learns patterns from data.

A simplified comparison is:

```text
RULE-BASED SYSTEM

Rules + Input Data
        ↓
     Decision
```

compared with:

```text
MACHINE LEARNING

Training Data
     ↓
   Model

Model + New Input
        ↓
    Prediction
```

In a rule-based system, humans explicitly decide the rules.

In machine learning, the system learns patterns from examples in the training data.

---

# What About Generative AI?

Systems such as ChatGPT are much more complex than a collection of `if` statements.

They are trained using very large quantities of data and use machine-learning models containing huge numbers of learned parameters.

However, the fundamental problem is related:

> **How can a computer use information to produce an appropriate response or decision?**

Your assignment explores this question using rules that you can see, understand and write yourself.

---

# Are `if` Statements Still Used in Modern AI?

Absolutely.

Even though modern AI models do not simply consist of thousands of `if` statements, ordinary programming logic is still used throughout AI applications.

For example, selection may be used for:

- checking whether input is valid
- deciding which model or service to use
- handling errors
- checking permissions
- deciding what information to display
- applying safety rules
- deciding what should happen next in an application

AI systems still need conventional software around them.
