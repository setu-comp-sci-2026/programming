# 4. Part A – Design Your Application

Before writing your Python program, you must plan your solution.

## 4.1 Application idea

Write a short description of your application.

For example:

> My program will help the user choose an activity for the weekend based on their age, budget, available time and preferences.

---

## 4.2 Identify your inputs

Identify the information that your program will ask the user to enter.

You must use at least **five pieces of user input**.

Complete a table similar to the following:

| InputData  |   Type     |   Example     |
| --------------------- | ------- | ----- |
| name                  | `str`   | Mairead |
| age                   | `int`   | 20    |
| budget                | `float` | 35.50 |
| weather               | `str`   | sunny |
| hours\_available      | `int`   | 4     |

Your program should use at least **three appropriate data types**.

For example:

- `str`
- `int`
- `float`
- Boolean values where appropriate
