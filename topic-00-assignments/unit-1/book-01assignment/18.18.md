# Important Advice

Start simple.

Do not try to build a very large application.

A small program that:

- works correctly
- contains good decision logic
- uses well-designed functions
- is thoroughly tested
- and can be clearly explained

will receive a stronger mark than a complicated program that you do not fully understand.

The aim of this assignment is not to demonstrate how much Python you can use.

The aim is to demonstrate that you can **design a solution, make decisions using Python, organise your code into functions, test your program and explain how it works**.
