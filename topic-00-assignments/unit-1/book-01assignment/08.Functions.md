# 8. Functions

Your program must contain at least **four functions that you have written yourself**.

Functions should be used to break your program into smaller, logical tasks.

For example:

```python
def display_welcome():
    print("Welcome to the Weekend Activity Picker")

```

Your program must include:

- a function with no parameters
- a function that accepts at least one parameter
- a function that returns a value

For example:

```python
def calculate_discount(price):
    discount = price * 0.10
    return price - discount

```

Try to avoid placing your entire program inside one large function.
