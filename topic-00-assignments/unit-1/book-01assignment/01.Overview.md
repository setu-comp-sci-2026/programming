## 1. Overview

In this assignment, you will design and develop a small interactive Python program that helps a user make a decision or receive a recommendation.

Your program should ask the user a series of questions, process their answers, and use selection statements to produce an appropriate result.

The purpose of this assignment is to demonstrate your understanding of the programming concepts covered during the first three weeks of the module.

These include:

- variables
- data types
- user input and output
- type conversion
- Boolean expressions
- selection using `if`, `elif` and `else`
- logical operators
- functions
- parameters
- return values

You are not expected to use programming concepts that have not yet been covered in class.
