# 5. Decision Rules

Before writing your program, write at least **five decision rules in plain English**.

For example:

> If the weather is sunny and the user has at least three hours available, recommend an outdoor activity.

> If the user's budget is less than €20, do not recommend an expensive activity.

> If the user is under 18, do not recommend an age-restricted activity.

> If the user wants an indoor activity and has less than two hours available, recommend watching a film.

Your final Python program should implement these rules.

The rules should produce several different possible outcomes.
