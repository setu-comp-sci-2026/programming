# 4. From Decision Program to Expert System

Your first assignment might have contained:

```python
if weather == "sunny" and hours >= 3:
    recommendation = "Go hiking"
```

The rule was part of your Python program.

In this project, you are working towards:

```text
                KNOWLEDGE BASE
                      |
          Questions – Rules – Advice
                      |
                      ↓
               INFERENCE ENGINE
                      |
                 User Answers
                      |
                      ↓
                 Conclusion
                      |
                      ↓
                    WHY?
```

This is an important step.

Your Python program becomes the **engine**.

Your Knowledge Base contains the **expertise**.
The Knowledge Base should be saved as a JSON file.  This file should be **readable** by your Python program and updatable via the program.

Changing the knowledge base can change the behaviour of the expert system without necessarily changing the engine that processes it.
