# 1. Overview

In Assignment 1, **Make My Decision!**, you developed a Python program that used information supplied by a user together with `if`, `elif` and `else` statements to make decisions.

In this assignment, you will take that idea much further.

You will design and develop your own **rule-based Expert System**.

An expert system attempts to capture knowledge about a particular subject and then uses that knowledge to help a user:

- solve a problem
- make a decision
- identify a possible cause
- receive advice
- receive a recommendation

The major difference between this project and Assignment 1 is that the knowledge used by your system should no longer be contained entirely within the Python program.

Instead, you will create a **Knowledge Base** containing the questions, rules and possible recommendations used by your system.

Your Python program will load this knowledge and use it to reach conclusions.
