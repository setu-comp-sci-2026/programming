# 8. An Important Principle – Knowledge is Data

One of the most important ideas in this assignment is:

> **The expert knowledge should be separated from the Python code that processes it.**

Consider the following program:

```python
if answer1 == "yes" and answer2 == "no":
    print("Recommendation A")
elif answer1 == "no" and answer3 == "yes":
    print("Recommendation B")
elif answer2 == "yes" and answer4 == "no":
    print("Recommendation C")
```

This may make decisions, but the expert knowledge is **hard-coded into the program**.

Your final expert system should take a different approach:

```text
KNOWLEDGE BASE
      |
      | Questions
      | Rules
      | Recommendations
      ↓
INFERENCE ENGINE
      |
      | applies the rules
      ↓
USER ANSWERS
      |
      ↓
RECOMMENDATION
```

The Python program should contain the logic for **processing rules**.

The Knowledge Base should contain the actual **expert knowledge**.
