# 19. The KnowledgeBase Class

A particularly useful class to consider is `KnowledgeBase`.

Conceptually:

```text
+--------------------------------+
|        KnowledgeBase           |
+--------------------------------+
| questions                      |
| rules                          |
| recommendations                |
+--------------------------------+
| load()                         |
| save()                         |
| add_question()                 |
| find_question()                |
| update_question()              |
| delete_question()              |
| add_rule()                     |
| ...                            |
+--------------------------------+
```

The `KnowledgeBase` object could therefore be responsible for managing what the expert system knows.

The `ExpertSystem` object could then be responsible for using that knowledge.

This is one possible design rather than a required implementation.
