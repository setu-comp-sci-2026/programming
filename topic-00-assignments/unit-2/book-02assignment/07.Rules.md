# 7. Rules

Rules represent the expertise in your system.

A rule might be expressed in plain English as:

> IF the computer does not power on  
> AND power lights are visible  
> AND the fan cannot be heard  
> THEN suggest a possible power supply problem.

In Assignment 1, you might have represented this directly in Python:

```python
if power == "no" and lights == "yes" and fan == "no":
    print("Possible power supply problem")
```

For this assignment, the aim is to eventually represent the **rule itself as data**.

For example:

```python
rule = {
    "id": "RULE1",
    "conditions": {
        "Q1": "no",
        "Q2": "yes",
        "Q3": "no"
    },
    "recommendation": "R2"
}
```

As a guide, your Knowledge Base should contain at least:

**20 meaningful rules.**

Rules should vary in complexity and should contribute towards different recommendations.
