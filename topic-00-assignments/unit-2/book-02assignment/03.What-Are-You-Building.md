# 3. What Are You Building?

Your finished system should contain four important components:

```text
                     EXPERT SYSTEM
                          |
        +-----------------+-----------------+
        |                 |                 |
   User Interface    Knowledge Base    Inference Engine
        |                 |                 |
   Ask Questions      Questions          Apply Rules
   Get Answers         Rules                 |
        |          Recommendations            |
        +-----------------+-----------------+
                          |
                    Recommendation
                          |
                       WHY?
                          |
                     Explanation
```

These components have different responsibilities.

## User Interface

Communicates with the user and collects their answers.

## Knowledge Base

Stores what the expert system **knows**.

## Inference Engine

Applies the knowledge and rules to the user's answers.

## Explanation Facility

Explains why a particular conclusion or recommendation was reached.
