# 10. Building the Knowledge Base

You will develop your Knowledge Base as you learn new Python concepts.

Initially, you might represent a question using a dictionary:

```python
question = {
    "id": "Q1",
    "text": "Does the computer power on?",
    "type": "yes_no",
    "category": "power"
}
```

Several questions could be stored in a list:

```python
questions = [
    {
        "id": "Q1",
        "text": "Does the computer power on?",
        "type": "yes_no"
    },
    {
        "id": "Q2",
        "text": "Are any power lights visible?",
        "type": "yes_no"
    }
]
```

As the module progresses, you will develop more sophisticated ways of representing and managing this information.
