# 5. Questions

Your system should contain a meaningful collection of questions.

As a guide, your finished Knowledge Base should contain approximately:

**15–20 or more questions/data points.**

Questions must contribute to the reasoning of the system.

For example:

```text
Q1: Does the computer power on?

Q2: Are any power lights visible?

Q3: Can you hear the fan?

Q4: Does the computer make a clicking sound?
```

Your system should support more than one type of question where appropriate.

For example:

- Yes/No questions
- Multiple-choice questions
- Numeric questions
