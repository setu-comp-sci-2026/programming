# Matching answers to troubleshooting rules

We want the program to select advice based on answers. The **first matching rule** should win.

Create **02_rule_matching.py** and use the knowledge.json file from Activity 01.

## Step 1: Load the knowledge

```python
import json


def load_knowledge(filename):
    with open(filename, "r", encoding="utf-8") as file:
        return json.load(file)
```

## Step 2: Ask questions

```python
def ask_questions(questions):
    answers = {}

    for question in questions:
        key = question["key"]
        answer = input(question["text"] + " (yes/no): ")
        answers[key] = answer.strip().lower()

    return answers
```

## Step 3: Check whether a rule matches

```python
def matches(rule, answers):
    for key, expected in rule["when"].items():
        if answers.get(key) != expected:
            return False
    return True
```

## Step 4: Return the first recommendation

```python
def recommend(rules, answers):
    for rule in rules:
        if matches(rule, answers):
            return rule["advice"]
    return "No matching rule. Ask for further help."
```

## Step 5: Run it

```python
knowledge = load_knowledge("knowledge.json")
answers = ask_questions(knowledge["questions"])
advice = recommend(knowledge["rules"], answers)
print("Recommendation:", advice)
```
