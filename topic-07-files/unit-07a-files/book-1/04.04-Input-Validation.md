# Input validation

Create a file called **04_validate_input.py**.

Input validation checks whether a value meets the rules of our program **before** we accept it.

## Step 1 — Check a dog's age

~~~python
age = int(input("Age (0 to 25): "))

if 0 <= age <= 25:
    print("Age accepted")
else:
    print("Age must be between 0 and 25")
~~~

Run the program with `4`, `-3` and `30`. Does this version let the user try again?

## Step 2 — Keep asking until the age is valid

~~~python
age = int(input("Age (0 to 25): "))

while age < 0 or age > 25:
    print("Please enter an age from 0 to 25")
    age = int(input("Age (0 to 25): "))

print("Accepted:", age)
~~~

**Predict:** Will the loop run for `-1`, `12` and `26`? Why do we use `or` rather than `and`?

## Step 3 — Validate a menu choice

~~~python
choice = input("Choose A, V or Q: ").strip().upper()

while choice not in ["A", "V", "Q"]:
    print("Invalid choice")
    choice = input("Choose A, V or Q: ").strip().upper()

print("You selected:", choice)
~~~
