# Make a journal

Create a file called **02_journal.py**.

Your program should ask for one note, save it and display all previous notes.

## Step 1 — Ask for a note

~~~python
note = input("Enter a journal note: ")
~~~

## Step 2 — Append the note

~~~python
with open("journal.txt", "a", encoding="utf-8") as file:
    file.write(note + "\n")
~~~

Why is `"a"` better than `"w"` for a journal?

## Step 3 — Display the journal

~~~python
print("\nYour journal:")
with open("journal.txt", "r", encoding="utf-8") as file:
    print(file.read())
~~~

## Mini exercise

1. Run the program and enter `Learned about files`.
2. Run it again and enter `Practised Python`.
3. Check that **both** notes appear.
4. Open `journal.txt` to see how Python stored the notes.
