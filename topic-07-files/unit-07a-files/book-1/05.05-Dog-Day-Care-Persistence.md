# Dog Day Care — load, change, save

Create a file called **05_dog_day_care.py**.

We will extend the Dog Day Care example from our CRUD work. The goal is to **validate a record before saving it**, then prove that the record is still available when the program restarts.

## Step 1 — Start with a list

~~~python
import json

dogs = [
    {"name": "Buddy", "age": 4},
    {"name": "Luna", "age": 2}
]
~~~

## Step 2 — Create a save function

~~~python
def save_dogs(dogs):
    with open("dogs.json", "w", encoding="utf-8") as file:
        json.dump(dogs, file, indent=4)
~~~

## Step 3 — Create a load function

~~~python
def load_dogs():
    with open("dogs.json", "r", encoding="utf-8") as file:
        return json.load(file)
~~~

**First run:** We need to create `dogs.json` before trying to read it. For this exercise, call `save_dogs(dogs)` once to create the starter file. After that, remove or comment out that starter save so it doesn't overwrite your changes on every run.

## Step 4 — Validate and add a dog

~~~python
def add_dog(dogs):
    name = input("Dog's name: ").strip()
    while name == "":
        name = input("Name cannot be blank. Try again: ").strip()

    age = int(input("Age (0 to 25): "))
    while age < 0 or age > 25:
        age = int(input("Enter an age from 0 to 25: "))

    dogs.append({"name": name, "age": age})
~~~

## Step 5 — Connect the steps

After creating your starter JSON file, use:

~~~python
dogs = load_dogs()
add_dog(dogs)
save_dogs(dogs)

for dog in dogs:
    print(f"{dog['name']} - {dog['age']} years old")
~~~
