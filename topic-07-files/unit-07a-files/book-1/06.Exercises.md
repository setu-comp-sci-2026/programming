# Exercises

Complete these after the guided activities. Use separate Python files, or build on your earlier programs.

## Exercise 1 — Persistent shopping list

Create a program that:

1. Asks the user to enter a shopping item.
2. Appends the item to `shopping.txt`.
3. Reads the file and displays the full shopping list.
4. Keeps previous items when run again.

**Extra practice:** Reject an empty item or one containing only spaces.

## Exercise 2 — Save and load books

Create a list of three book dictionaries. Each book should have a `title`, `author` and `year`.

1. Save the list to `books.json` using `json.dump()`.
2. Load it back using `json.load()`.
3. Display each book in a readable format.
4. Add another book and save the updated list.

## Exercise 3 — Validate a rating

Ask the user to enter a rating between **1 and 5**.

- Use a `while` loop to keep asking until the rating is valid.
- Display the accepted rating.
- Put your validation code into a function called `get_rating()` that returns the number.

Assume numeric input for now.

## Exercise 4 — Persistent movie manager

Extend the Movie CRUD program from the previous lab.

1. Create a starter `movies.json` file from your existing movie list.
2. Load the movies at the start of the program.
3. Save the movies after adding, updating or deleting a record.
4. Run the program again and check that your changes remain.

**Tip:** Keep your existing CRUD functions. Add separate `load_movies()` and `save_movies()` functions.

## Exercise 5 — Test your program

For either the Dog Day Care or Movie Manager program, write down the **input**, **expected result** and **actual result** for at least five tests. Include a valid value, a boundary value, an invalid value and a restart/persistence test.
