# Getting to know files, persistence and input validation

text files · file modes · `with open()` · JSON · input validation · load → change → save

By the end of this lab, you should be able to:

- Explain why data stored in a Python list disappears when the program finishes.
- Write, append and read text files using `with open()`.
- Choose between the `"w"`, `"a"` and `"r"` file modes.
- Save and load lists of dictionaries using JSON.
- Validate values using `if` statements and `while` loops.
- Apply the **load → change → save** pattern to a simple Dog Day Care program.

## Before you begin

You should already be comfortable with variables, input/output, selection, loops, functions, lists and dictionaries.

**This week's boundary:** We assume users enter numbers when asked for numbers. Handling non-numeric input with `try`/`except`, and recovering from missing files, will be covered in Week 8.
