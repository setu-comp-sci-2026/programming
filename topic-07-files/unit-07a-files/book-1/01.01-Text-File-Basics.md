# Text file basics

Create a file called **01_text_file_basics.py**.

A variable or list exists in memory while the program runs. A file allows information to remain after the program stops.

## Write a file

~~~python
with open("notes.txt", "w", encoding="utf-8") as file:
    file.write("First note\n")
~~~

Run the program and open `notes.txt` in VS Code.

- `"w"` creates a file or **overwrites** an existing one.
- `with open()` automatically closes the file when the indented block finishes.
- `"\n"` starts a new line.

## Append a second note

Add this code **after** the first block:

~~~python
with open("notes.txt", "a", encoding="utf-8") as file:
    file.write("Another note\n")
~~~

`"a"` adds to the end without deleting the current contents.

## Read the file

~~~python
with open("notes.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
~~~

`"r"` reads an existing file. `strip()` removes the newline when displaying each line.
