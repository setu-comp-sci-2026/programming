# 7. DELETE — remove an account

Add this method inside `Bank`:

~~~python
    def delete_account(self, account_no):
        account = self.find_account(account_no)
        if account is None:
            return False
        self.accounts.remove(account)
        return True
~~~

## Test the method

~~~python
print(bank.delete_account("A004"))
print(bank.delete_account("A004"))
bank.list_accounts()
~~~

## Questions

1. Why does the first deletion return `True` and the second `False`?
2. Why do we call `find_account()` before `remove()`?
3. If another variable still refers to the removed account object, does removing it from the bank's list necessarily destroy the object?
