# 1. Create a BankAccount class

Create **bank_lab.py**. Start with the following class:

~~~python
class BankAccount:
    def __init__(self, account_no, name, balance=0):
        if balance < 0:
            raise ValueError("Balance cannot be negative")
        self.account_no = account_no
        self.name = name
        self.balance = balance

    def __str__(self):
        return f"{self.account_no}: {self.name} - €{self.balance:.2f}"
~~~

Under the class, add this **test code**:

~~~python
alice = BankAccount("A001", "Alice", 500)
bob = BankAccount("A002", "Bob", 1200)
print(alice)
print(bob)
~~~

## Check your understanding

1. Which line creates an **object**?
2. What does `self` refer to inside `__init__`?
3. What method runs when you use `print(alice)`?
4. What happens if you try `BankAccount("A003", "Charlie", -20)`? Why?
