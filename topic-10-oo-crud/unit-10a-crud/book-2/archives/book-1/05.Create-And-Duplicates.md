# 5. CREATE — add accounts safely

Appending directly to `bank.accounts` works, but it does not check for duplicate account numbers. The `Bank` class should manage that rule.

Add this method inside `Bank`:

~~~python
    def add_account(self, account):
        if self.find_account(account.account_no) is not None:
            return False
        self.accounts.append(account)
        return True
~~~

For this exercise, create a **fresh** bank so that you can test adding accounts through the new method:

~~~python
bank = Bank()
print(bank.add_account(alice))
print(bank.add_account(bob))
print(bank.add_account(charlie))
print(bank.add_account(alice))
print(len(bank.accounts))
~~~
