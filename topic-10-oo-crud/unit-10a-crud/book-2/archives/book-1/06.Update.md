# 6. UPDATE — change an existing account

Updating starts by **finding** the correct object.

Add this method inside `Bank`:

~~~python
    def rename_account(self, account_no, new_name):
        account = self.find_account(account_no)
        if account is None or new_name.strip() == "":
            return False
        account.name = new_name.strip()
        return True
~~~

Test it:

~~~python
print(bank.rename_account("A002", "Robert"))
print(bank.find_account("A002"))
~~~
