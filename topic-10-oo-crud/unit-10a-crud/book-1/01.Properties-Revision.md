~~~python
class Person:
    def __init__(self, name, age):
        self._name = name
        self._age = age

    @property
    def name(self):
        return self._name

    @property
    def age(self):
        return self._age

    @age.setter
    def age(self, value):
        if value < 0 or value > 150:
            raise ValueError("Invalid age")
        self._age = value

p = Person("Alice", 25)
print(p.name)
p.age = 26
print(p.age)
~~~

1. Why does `p.age` not require parentheses?
2. What happens if we execute `p.age = -5`?
3. What happens if we execute `p.name = "Bob"`? Why?
4. Why do we store `_age` rather than `age` inside the setter?
