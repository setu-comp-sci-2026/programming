# Week 10 Monday Lab — Object-Oriented CRUD

**Scenario:** A bank has many customers, each with an account. We will use two classes: `BankAccount` for one account, and `Bank` to manage a list of account objects.

By the end of the lab you should be able to:

- create objects from a class and use their methods;
- store **objects** in a list belonging to another object;
- implement **Create, Read, Update, Delete (CRUD)** using methods;
- search for an object by a unique account number;
- explain `None`, `return`, `pass`, `raise`, and Boolean results.

## Files for today

Create a folder named `week10_bank` and work in **one Python file**, `bank_lab.py`. Add each new section to the same file as you progress. Run it after each task.

**Today's scope:** No menus, JSON, file handling or `@property` implementation. Those are not required for this lab.
