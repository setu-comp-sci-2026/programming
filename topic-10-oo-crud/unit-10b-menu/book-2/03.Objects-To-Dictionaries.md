# 3. Prepare objects for JSON
Add this method inside BankAccount:

~~~python
def to_dict(self):
        return {"account_no": self.account_no,
                "name": self.name, "balance": self.balance}
~~~


Create a Bank with two accounts. Use a loop to build a list of dictionaries by calling to_dict on each account. Print the list. Try `json.dumps(records, indent=4)` after importing json. Compare with trying to dump the BankAccount object itself (catch TypeError).

**Remember:** to_dict returns a new dictionary; it does not save a file. Use public properties rather than `_balance` etc.
