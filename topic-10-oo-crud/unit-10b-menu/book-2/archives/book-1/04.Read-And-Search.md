# 4. READ — display and find accounts

Add the following methods **inside the `Bank` class**:

~~~python
    def list_accounts(self):
        for account in self.accounts:
            print(account)

    def find_account(self, account_no):
        for account in self.accounts:
            if account.account_no == account_no:
                return account
        return None
~~~

Test them **below your classes**:

~~~python
bank.list_accounts()

found = bank.find_account("A002")
if found is not None:
    print("Found:", found.name)
else:
    print("Account not found")
~~~

## Important ideas

- `return account` returns an **object**, not just a message.
- `return None` signals that no matching object was found.
- `is None` / `is not None` are the preferred checks for `None`.
- `print()` displays a result; `return` lets another part of the program **use** it.
