# 2. Let the account protect its data

An account should control deposits and withdrawals. Add these **two methods inside** `BankAccount`, at the same indentation level as `__str__`.

~~~python
    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Deposit must be positive")
        self.balance += amount

    def withdraw(self, amount):
        if amount <= 0:
            raise ValueError("Withdrawal must be positive")
        if amount > self.balance:
            raise ValueError("Insufficient funds")
        self.balance -= amount
~~~

Add this test code **below the class**:

~~~python
alice.deposit(100)
alice.withdraw(50)
print(alice)
~~~
