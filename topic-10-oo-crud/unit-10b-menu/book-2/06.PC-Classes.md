# 6. Refactor the PC Troubleshooter
Create a separate folder `pc_troubleshooter`. Keep the existing procedural version as a backup. We are changing the organisation, not the rule behaviour.

Create question.py, rule.py and troubleshooter.py using these supplied classes from the lecture.

## question.py

~~~python
class Question:
    def __init__(self, key, text):
        self.key = key
        self.text = text

    def __str__(self):
        return self.text
~~~
## rule.py

~~~python
class Rule:
    def __init__(self, conditions, advice):
        self.conditions = conditions
        self.advice = advice

    def matches(self, answers):
        for key, expected in self.conditions.items():
            if answers.get(key) != expected:
                return False
        return True
~~~
## troubleshooter.py

~~~python
class Troubleshooter:
    def __init__(self):
        self.questions = []
        self.rules = []

    def recommend(self, answers):
        for rule in self.rules:
            if rule.matches(answers):
                return rule.advice
        return "No matching rule. Ask for further help."
~~~
