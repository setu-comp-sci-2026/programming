# 5. Add a diagnostic log
Add the datetime import, LOG_FILE constant and this helper to storage.py:

~~~python
from datetime import datetime
LOG_FILE = DATA_FILE.parent / "bank.log"

def log_event(message):
    LOG_FILE.parent.mkdir(parents=True, exist_ok=True)
    stamp = datetime.now().isoformat(timespec="seconds")
    with open(LOG_FILE, "a", encoding="utf-8") as file:
        file.write(f"{stamp} {message}\n")
~~~
Import log_event in main.py. Call it after successful add, rename, delete and save, and when a duplicate is rejected. Example: `log_event("INFO Account added")`. Avoid names, balances or other unnecessary personal information. Handle file errors without claiming an operation was saved when it was not.

Run twice and inspect bank.log. Explain why the log uses append mode but accounts.json uses write mode. A log is not the current account list.
