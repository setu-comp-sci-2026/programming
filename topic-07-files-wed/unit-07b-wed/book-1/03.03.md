# Relative file paths

A file can exist on your computer but Python may still report **FileNotFoundError**. This is often because Python is looking in a different folder.

## Easiest way to fix this
To change this, 
 1. Go to your Visual Studio Code  File -> Preferences-> Settings
 2. Go to search bar (at top of window)
 3. Type 
```python
exectute in file dir
```
4. This will bring up a window that has a tick box - this reads 'When executing a file in the terminal, whether to use execute in the file's directory, instead of the current open folder.' - tick the box and save the setting.

# Alternative solutions
## Step 1: Find your working directory

Create **03_file_paths.py**:

```python
import os

print("Current working directory:", os.getcwd())
```

Run it in VS Code. The **current working directory** (CWD) is the starting point for relative paths.

## Step 2: Use a subfolder

Create this structure:

```text
WednesdayPersistenceLab/
    03_file_paths.py
    data/
        message.txt
```

Put `Hello from the data folder!` into `message.txt`.

```python
with open("data/message.txt", "r", encoding="utf-8") as file:
    print(file.read())
```

This works **when the CWD is `WednesdayPersistenceLab`**.

## Step 3: Find a file relative to the script

```python
from pathlib import Path

folder = Path(__file__).resolve().parent
filename = folder / "data" / "message.txt"

with open(filename, "r", encoding="utf-8") as file:
    print(file.read())
```

**Path(__file__).resolve().parent** finds the folder containing the Python script, even if the working directory is different.
