## Exercise 1 — JSON question viewer

```python
import json

with open("knowledge.json", "r", encoding="utf-8") as file:
    knowledge = json.load(file)

for number, question in enumerate(knowledge["questions"], start=1):
    print(f"{number}. {question['text']}")

print("Number of questions:", len(knowledge["questions"]))
```

## Exercise 2 — Validate yes/no answers

```python
def get_yes_no(prompt):
    while True:
        answer = input(prompt + " (yes/no): ").strip().lower()
        if answer == "yes" or answer == "no":
            return answer
        print("Please enter yes or no.")

print(get_yes_no("Does the computer turn on?"))
```

## Exercise 3 — Relative paths

```python
import os
from pathlib import Path

print("Working directory:", os.getcwd())

with open("files/notice.txt", "r", encoding="utf-8") as file:
    print(file.read())

folder = Path(__file__).resolve().parent
filename = folder / "files" / "notice.txt"
with open(filename, "r", encoding="utf-8") as file:
    print(file.read())
```

The first path is relative to the current working directory; the second is built relative to the Python script.

## Exercise 4 — `main()`

```python
import json


def show_questions(questions):
    for question in questions:
        print(question["text"])


def main():
    with open("knowledge.json", "r", encoding="utf-8") as file:
        knowledge = json.load(file)
    show_questions(knowledge["questions"])


if __name__ == "__main__":
    main()
```

## Exercise 5 — Persistence

Each run appends one dictionary to the history list. After three successful runs, the JSON file should contain three records, each with `time`, `answers` and `advice`. Saving a new one-item list with `"w"` would overwrite earlier records.

## PC Troubleshooter — recommended tests

| Answers | Expected outcome |
|---|---|
| `power_on=no`, `display_on=no` | Power cable advice |
| `power_on=yes`, `display_on=no` | Monitor connection advice |
| `power_on=yes`, `display_on=yes` | Restart / further checks advice |
| `power_on=MAYBE` | Ask again until yes or no |

**Challenge hint:** A rule with two conditions must appear before a broader rule with only one condition, otherwise the broader rule may match first.
