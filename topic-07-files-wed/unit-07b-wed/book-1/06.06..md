# PC Troubleshooter — adding a JSON knowledge base

This is our **continuing PC Troubleshooter example**. We are building on the earlier version that asked questions and used `if` statements to recommend solutions. Today we will store the **questions and rules in JSON**, load them using a script-relative path, organise the code using `main()` and save a consultation history.

## Project structure

Create the following files:

```text
PC_Troubleshooter/
    troubleshooter.py
    knowledge.json
    data/
```

The `data` folder will hold `history.json`. You do not need to create `history.json` yourself.

## Step 1: Create the knowledge base

Enter the following in **knowledge.json**:

```json
{
  "questions": [
    {"key": "power_on", "text": "Does the computer turn on?"},
    {"key": "display_on", "text": "Is there an image on the screen?"}
  ],
  "rules": [
    {"when": {"power_on": "no"}, "advice": "Check the power cable and socket."},
    {"when": {"power_on": "yes", "display_on": "no"}, "advice": "Check the monitor connection."},
    {"when": {"power_on": "yes", "display_on": "yes"}, "advice": "Try restarting the computer or checking other symptoms."}
  ]
}
```

## Step 2: Load knowledge from the correct folder

Start **troubleshooter.py** with:

```python
import json
from pathlib import Path
from datetime import datetime

BASE_FOLDER = Path(__file__).resolve().parent
KNOWLEDGE_FILE = BASE_FOLDER / "knowledge.json"
HISTORY_FILE = BASE_FOLDER / "data" / "history.json"


def load_knowledge():
    with open(KNOWLEDGE_FILE, "r", encoding="utf-8") as file:
        return json.load(file)
```

`BASE_FOLDER` is the folder containing `troubleshooter.py`, so the knowledge file can be found even when VS Code uses a different working directory.

## Step 3: Ask and validate questions

Add:

```python
def ask_questions(questions):
    answers = {}

    for question in questions:
        while True:
            answer = input(question["text"] + " (yes/no): ").strip().lower()
            if answer == "yes" or answer == "no":
                answers[question["key"]] = answer
                break
            print("Please enter yes or no.")

    return answers
```

## Step 4: Match the rules

Add:

```python
def matches(rule, answers):
    for key, expected in rule["when"].items():
        if answers.get(key) != expected:
            return False
    return True


def recommend(rules, answers):
    for rule in rules:
        if matches(rule, answers):
            return rule["advice"]
    return "No matching rule. Ask for further help."
```

The first matching rule supplies the recommendation.

## Step 5: Save the consultation history

Each consultation should be a dictionary containing a timestamp, the answers and the advice. We save a **list** of these records in JSON.

```python
def save_history(answers, advice):
    record = {
        "time": datetime.now().isoformat(timespec="seconds"),
        "answers": answers,
        "advice": advice
    }

    history = []
    try:
        with open(HISTORY_FILE, "r", encoding="utf-8") as file:
            history = json.load(file)
    except FileNotFoundError:
        pass  # No history file yet: start a new list

    history.append(record)

    with open(HISTORY_FILE, "w", encoding="utf-8") as file:
        json.dump(history, file, indent=4)
```

**Important:** The `data` folder must exist. We only handle a *missing history file* here. If the JSON is damaged, the program should report the error rather than silently erase previous records. We will explore exceptions in more detail next week.

## Step 6: Add `main()`

```python
def main():
    knowledge = load_knowledge()
    answers = ask_questions(knowledge["questions"])
    advice = recommend(knowledge["rules"], answers)

    print("
Recommendation:", advice)
    save_history(answers, advice)
    print("Consultation saved.")


if __name__ == "__main__":
    main()
```
