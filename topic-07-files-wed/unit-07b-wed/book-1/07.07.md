# Exercises

Complete these after the guided activities. Create separate Python files where appropriate.

## Exercise 1 — JSON question viewer

Using `knowledge.json` from Activity 01, display each question in a numbered list:

```text
1. Does the computer turn on?
2. Is there an image on the screen?
```

**Extension:** Display how many questions are stored.

## Exercise 2 — Validate yes/no answers

Write a function called `get_yes_no(prompt)` that:

1. Accepts a question as a parameter.
2. Keeps asking until the user enters `yes` or `no`.
3. Accepts uppercase or lowercase answers.
4. Returns the valid answer in lowercase.

Test it with `YES`, `No`, `maybe` and an empty answer.

## Exercise 3 — Working directory investigation

Create `files/notice.txt` and write a short message into it. Then:

1. Print the current working directory using `os.getcwd()`.
2. Read the file using the relative path `files/notice.txt`.
3. Read it again using a path based on `Path(__file__).resolve().parent`.
4. Explain when the second approach is more reliable.

## Exercise 4 — Add a `main()` function

Take your earlier JSON question viewer and move the running code into a `main()` function. Add:

```python
if __name__ == "__main__":
    main()
```

Keep your other functions outside `main()`.

## Exercise 5 — Test PC Troubleshooter persistence

Run the continuing PC Troubleshooter at least three times with different answers. Inspect `data/history.json` and answer:

- How many records are saved?
- What information is stored in each record?
- Why do earlier records remain after the program closes?
- What would happen if the program saved only the latest record using `"w"` without first loading the history?
