# JSON, relative file paths and main()

JSON knowledge bases · lists of dictionaries · rule matching · session history · relative paths · pathlib · main()

By the end of this lab, you should be able to:

- Read structured data from a JSON file using json.load().
- Explain why a rule-based program can store its knowledge separately from its Python code.
- Use dictionaries to record answers and match them against rules.
- Save a history of consultations in JSON.
- Identify the current working directory and use relative paths.
- Use pathlib to find files relative to a Python script.
- Organise a program with main() and the standard __name__ check.

## Before you begin

You should already be comfortable with functions, if statements, loops, dictionaries, lists and reading/writing files. These activities build on Monday's persistence lab.

**Week 8 preview:** Some examples show FileNotFoundError and a small try/except block for missing history files, as in the lecture. Detailed exception handling and debugging are covered next week.


> **Remember:** JSON stores data. Python functions decide what to do with that data.
