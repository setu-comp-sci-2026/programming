# Code from Class: Standard Library

A **module** is usually a `.py` file containing reusable code. Python includes a **standard library**, so we can use modules such as `random`, `math` and `json` without installing them separately.

## Example 1 — Roll a die
Create `dice.py`:

```python
import random

number = random.randint(1, 6)
print("Dice roll:", number)
```

Run it several times. `random` is the module; `randint()` is a function inside it. The dot means *look inside the module*.

**Try it:** Change the upper limit to 20. What is the smallest possible result? What is the largest?

## Example 2 — Revisit JSON

```python
import json

student = {"name": "Alex", "mark": 78}
with open("student.json", "w") as file:
    json.dump(student, file, indent=4)

with open("student.json", "r") as file:
    loaded_student = json.load(file)

print(loaded_student["name"])
```

**Think:** Why do we write `json.dump()` rather than just `dump()`?
