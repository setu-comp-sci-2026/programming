# Code from Class: What Happens During an Import?

Python runs a module's top-level statements when it is first imported in a running process.

## Example 1 — An unexpected message
Create `greetings.py`:

```python
print("Module is loading")

def say_hello():
    print("Hello!")
```

Create `main.py`:

```python
import greetings

print("Main program is starting")
greetings.say_hello()
```

**Predict:** In what order will the three messages appear? Run `main.py` and check.

## Example 2 — Optional: `__name__` guard
Change `greetings.py` to:

```python
def say_hello():
    print("Hello!")

if __name__ == "__main__":
    print("Testing greetings directly")
    say_hello()
```

Run `greetings.py` directly. Then run `main.py` again. What changes?

**Remember:** The `if __name__ == "__main__":` pattern is useful for test code that should run only when a file is executed directly. You do not need to memorise it today.
