# Code from Class: Two Ways to Import

## Example 1 — Import the whole module

```python
import math

print(math.sqrt(25))
print(math.pi)
```

## Example 2 — Import one name

```python
from math import sqrt

print(sqrt(25))
```

Both examples calculate the same square root. The first style makes the source of the function clearer: `math.sqrt(...)`.

## Compare the syntax

| Import statement | Function call |
|---|---|
| `import math` | `math.sqrt(9)` |
| `from math import sqrt` | `sqrt(9)` |

**Try it:** Change `25` to `81`. Then try `sqrt(-1)` and read the exception message. What type of exception is raised?
