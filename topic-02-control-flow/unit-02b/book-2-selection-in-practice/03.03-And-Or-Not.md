# Logical operators

Logical operators allow us to combine or change conditions.

Python provides:

- `and`
- `or`
- `not`

## `and`

Both conditions must be true.

Create **03_logical_operators.py**.

~~~python
age = int(input("Age: "))
height = int(input("Height in cm: "))

if age >= 12 and height >= 140:
    print("You may go on the ride")
else:
    print("Requirements not met")
~~~

Test:

| age | height | expected |
| --- | --- | --- |
| 12 | 140 | |
| 11 | 140 | |
| 12 | 139 | |
| 15 | 160 | |

## `or`

At least one condition must be true.

~~~python
age = int(input("Age: "))
student = input("Are you a student? yes/no: ").lower()

if age >= 65 or student == "yes":
    print("Discount applies")
else:
    print("Standard price")
~~~

## `not`

`not` reverses a Boolean value.

~~~python
logged_in = False

if not logged_in:
    print("Please log in")
~~~
