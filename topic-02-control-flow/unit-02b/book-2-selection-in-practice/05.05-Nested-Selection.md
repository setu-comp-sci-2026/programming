# Nested selection

An `if` statement can appear inside another `if` statement.

## Example - Cinema ticket

Create **05_nested.py**.

A person must be at least 12 to see a film.

If they are allowed in, students receive a reduced ticket price.

~~~python
age = int(input("Age: "))

if age >= 12:
    student = input("Are you a student? yes/no: ").lower()

    if student == "yes":
        print("Ticket price: €8")
    else:
        print("Ticket price: €12")
else:
    print("You are too young for this film")
~~~

Run the program using several combinations.

## Trace

What happens for:

1. age `10`
2. age `15`, student `yes`
3. age `30`, student `no`
