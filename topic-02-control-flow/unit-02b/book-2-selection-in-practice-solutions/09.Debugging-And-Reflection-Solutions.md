# Debugging and reflection - Solutions

## Debugging 1

Incorrect:

~~~python
if age >= 18 and <= 65:
~~~

Correct:

~~~python
if age >= 18 and age <= 65:
    print("Working age range")
~~~

or, more naturally in Python:

~~~python
if 18 <= age <= 65:
    print("Working age range")
~~~

## Debugging 2

The distinction condition must be checked first.

~~~python
mark = int(input("Mark: "))

if mark >= 70:
    print("Distinction")
elif mark >= 40:
    print("Pass")
else:
    print("Fail")
~~~

## Debugging 3

Use `or`:

~~~python
age = int(input("Age: "))
student = input("Student? yes/no: ").lower()

if age >= 65 or student == "yes":
    print("Discount")
else:
    print("No discount")
~~~

## Debugging 4

The boundaries must be inclusive:

~~~python
if mark >= 0 and mark <= 100:
    print("Valid")
~~~

or:

~~~python
if 0 <= mark <= 100:
    print("Valid")
~~~

## Reflection - Suggested answers

### 1. What is the difference between `if` and `if-else`?

`if` runs code only when a condition is true.

`if-else` chooses between two possible paths.

### 2. When would you use `elif`?

Use `elif` when there are several mutually exclusive choices.

### 3. What does `and` mean?

Both conditions must be true.

### 4. What does `or` mean?

At least one of the conditions must be true.

### 5. Why is indentation important?

Python uses indentation to show which statements belong to a block.

### 6. Why should boundary values be tested?

They help find errors involving operators such as `<`, `<=`, `>`, and `>=`.

### 7. When might separate `if` statements be better?

When more than one condition can be true and more than one action may need to happen.
