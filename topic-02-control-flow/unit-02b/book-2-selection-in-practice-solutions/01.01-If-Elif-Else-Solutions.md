# `if-elif-else` - Solutions

## Grade classification

~~~python
mark = int(input("Enter mark: "))

if mark >= 70:
    print("Distinction")
elif mark >= 60:
    print("Merit 1")
elif mark >= 50:
    print("Merit 2")
elif mark >= 40:
    print("Pass")
else:
    print("Fail")
~~~

## Trace for mark = 65

| condition | result | branch executed? |
| --- | --- | --- |
| `mark >= 70` | False | No |
| `mark >= 60` | True | Yes |
| `mark >= 50` | Not checked | No |
| `mark >= 40` | Not checked | No |

The output is:

~~~
Merit 1
~~~

## Weather description

~~~python
temperature = float(input("Enter temperature: "))

if temperature >= 25:
    print("Hot")
elif temperature >= 15:
    print("Warm")
elif temperature >= 5:
    print("Cool")
else:
    print("Cold")
~~~
