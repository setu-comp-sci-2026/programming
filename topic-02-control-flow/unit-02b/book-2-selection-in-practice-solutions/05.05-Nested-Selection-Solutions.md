# Nested selection - Solutions

## Cinema ticket trace

For age `10`:

~~~
You are too young for this film
~~~

For age `15` and student `yes`:

~~~
Ticket price: €8
~~~

For age `30` and student `no`:

~~~
Ticket price: €12
~~~

## Account access

~~~python
username = input("Username: ")

if username == "student":
    pin = input("PIN: ")

    if pin == "1234":
        print("Access granted")
    else:
        print("Incorrect PIN")
else:
    print("Unknown user")
~~~

## Alternative with `and`

This could also be written as:

~~~python
username = input("Username: ")
pin = input("PIN: ")

if username == "student" and pin == "1234":
    print("Access granted")
else:
    print("Access denied")
~~~

However, the nested version allows more specific messages.
