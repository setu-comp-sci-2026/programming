# Separate `if` or `elif`? - Solutions

## Answers

1. **Separate `if` statements**  
   A number can be positive and even at the same time.

2. **`if-elif-else`**  
   A student should receive one grade classification.

3. **Separate `if` statements**  
   A customer can be a member and also qualify for free delivery.

4. **`if-elif-else`**  
   A temperature should normally receive one classification.

## Example

~~~python
number = int(input("Enter a number: "))

if number > 0:
    print("Positive")

if number % 2 == 0:
    print("Even")
~~~

If the user enters `8`, both conditions are true, so both messages are displayed.
