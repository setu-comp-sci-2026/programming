# Logical operators - Solutions

## `and`

Both conditions must be true.

For:

~~~python
if age >= 12 and height >= 140:
~~~

the table is:

| age | height | expected |
| --- | --- | --- |
| 12 | 140 | Allowed |
| 11 | 140 | Not allowed |
| 12 | 139 | Not allowed |
| 15 | 160 | Allowed |

## Club entry

One possible solution:

~~~python
age = int(input("Age: "))
has_ticket = input("Do you have a ticket? yes/no: ").lower()

if age >= 18 and has_ticket == "yes":
    print("Entry allowed")
else:
    print("Entry denied")
~~~

## `or`

For:

~~~python
if age >= 65 or student == "yes":
~~~

the discount applies if either condition is true.

## `not`

~~~python
logged_in = False

if not logged_in:
    print("Please log in")
~~~

Because `logged_in` is `False`, `not logged_in` becomes `True`.
