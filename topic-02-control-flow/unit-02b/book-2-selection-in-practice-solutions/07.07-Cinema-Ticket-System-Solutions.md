# Cinema ticket system - Solution

One possible complete solution is:

~~~python
film_rating = int(input("Film age rating: "))
age = int(input("Customer age: "))

if age < film_rating:
    print("Sorry, you are too young for this film")
else:
    if age < 16:
        ticket_price = 7.0

    elif age >= 65:
        ticket_price = 8.0

    else:
        student = input("Are you a student? yes/no: ").lower()

        if student == "yes":
            ticket_price = 10.0
        else:
            ticket_price = 12.0

    print("Ticket price: €", ticket_price)
~~~

## Test cases

| age | rating | student | expected |

| 12 | 12 | - | €7 |

| 30 | 18 | no | €12 |
| 65 | 15 | - | €8 |

## Challenge - Tuesday price

One possible extension:

~~~python
film_rating = int(input("Film age rating: "))
age = int(input("Customer age: "))
day = input("Day of week: ").lower()

if age < film_rating:
    print("Sorry, you are too young for this film")
else:
    if day == "tuesday":
        ticket_price = 6.0

    elif age < 16:
        ticket_price = 7.0

    elif age >= 65:
        ticket_price = 8.0

    else:
        student = input("Are you a student? yes/no: ").lower()

        if student == "yes":
            ticket_price = 10.0
        else:
            ticket_price = 12.0

    print("Ticket price: €", ticket_price)
~~~

The Tuesday condition is checked before the normal ticket categories because Tuesday overrides the standard price.
