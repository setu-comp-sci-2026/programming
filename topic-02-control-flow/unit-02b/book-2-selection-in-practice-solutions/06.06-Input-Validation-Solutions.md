# Input validation - Solutions

## Mark validation

~~~python
mark = int(input("Enter mark (0-100): "))

if 0 <= mark <= 100:
    if mark >= 40:
        print("Pass")
    else:
        print("Fail")
else:
    print("Invalid mark")
~~~

## Age validator

~~~python
age = int(input("Enter age: "))

if 0 <= age <= 120:
    print("Age accepted")
else:
    print("Invalid age")
~~~

At this stage, the program only detects invalid input.

It does not yet repeatedly ask the user for another value.
