# `if-elif-else`

Use `if-elif-else` when there are several mutually exclusive outcomes.

## Example 1 - Grade classification

Create **01_grades.py**.

~~~python
mark = int(input("Enter mark: "))

if mark >= 70:
    print("Distinction")
elif mark >= 60:
    print("Merit 1")
elif mark >= 50:
    print("Merit 2")
elif mark >= 40:
    print("Pass")
else:
    print("Fail")
~~~

Test:

- `85`
- `70`
- `69`
- `60`
- `59`
- `50`
- `40`
- `39`

## Why does order matter?

Consider:

~~~python
if mark >= 40:
    print("Pass")
elif mark >= 70:
    print("Distinction")
~~~

What happens if `mark` is `85`?

Python checks conditions from top to bottom and stops when it finds the first true branch.
