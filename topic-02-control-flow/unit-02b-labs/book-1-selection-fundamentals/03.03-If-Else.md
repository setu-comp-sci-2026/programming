# `if-else`

Sometimes we want one action when a condition is true and a different action when it is false.

## Example 1 - Pass or fail

Create **03_if_else.py**.

~~~python
mark = int(input("Enter your mark: "))

if mark >= 40:
    print("Pass")
else:
    print("Fail")
~~~

Test with:

- `25`
- `39`
- `40`
- `75`

## Example 2 - Even or odd

Create **03_even_odd.py**.

~~~python
number = int(input("Enter a whole number: "))

if number % 2 == 0:
    print("Even")
else:
    print("Odd")
~~~

Test several numbers.

Why does `% 2` help us decide whether a number is even?
