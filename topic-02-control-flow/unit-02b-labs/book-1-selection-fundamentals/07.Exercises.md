# Exercises

Complete these exercises after working through the examples.

## Exercise 1 - Voting age

Ask the user for their age.

Display whether they are old enough to vote at age 18.

## Exercise 2 - Free shipping

Ask for an order total.

Orders of €50 or more receive free shipping.

Display an appropriate message.

## Exercise 3 - Pass or fail

Ask for a mark.

A mark of 40 or higher is a pass.

Display `Pass` or `Fail`.

## Exercise 4 - PIN check

Ask the user to enter a PIN.

If it matches `"1234"`, display:

~~~
Correct PIN
~~~

Otherwise display:

~~~
Incorrect PIN
~~~

## Exercise 5 - Divisible by 5

Ask for a whole number.

Use the modulo operator `%` to decide whether it is divisible by 5.

## Exercise 6 - Ticket price

Ask the user for their age.

If they are under 16, the ticket costs €7.

Otherwise, the ticket costs €12.

Display the ticket price.

## Exercise 7 - Debugging

Fix this program:

~~~python
score = int(input("Score: "))

if score >= 10
print("Target reached")
else
    print("Keep trying")
~~~
