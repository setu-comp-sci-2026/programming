# Boundaries and debugging

Small changes to comparison operators can change the meaning of a program.

## Example - Theme park ride

A person must be at least 120 cm tall to use a ride.

Which condition is correct?

~~~python
if height > 120:
~~~

or:

~~~python
if height >= 120:
~~~

The second condition includes someone who is exactly 120 cm tall.

## Task 1 - Test the boundary

Create **05_boundaries.py**.

~~~python
height = int(input("Enter height in cm: "))

if height >= 120:
    print("You may go on the ride")
else:
    print("Sorry, you are not tall enough")
~~~
