# Lab - Selection Fundamentals

In this lab, you will practise making decisions in Python.

You will work through the steps in order. Each step introduces a small idea and gives you a chance to test it before moving on.

By the end of the lab, you should be able to:

- create Boolean expressions
- use comparison operators
- write simple `if` statements
- write `if-else` statements
- use indentation correctly
- make decisions using numbers and strings
- identify boundary-value errors
- trace a selection statement

## Before you begin

Create a folder called:

~~~
selection-fundamentals
~~~

Open this folder in VS Code.

You will create a separate Python file for each step.

Start with **01_boolean_expressions.py**.
