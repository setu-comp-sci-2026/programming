# Input validation with selection

Programs should not blindly assume that all input is sensible.

At this stage, we can use selection to detect invalid values.

## Example 1 - Mark validation

Create **06_validation.py**.

~~~python
mark = int(input("Enter mark (0-100): "))

if 0 <= mark <= 100:
    if mark >= 40:
        print("Pass")
    else:
        print("Fail")
else:
    print("Invalid mark")
~~~

Test:

- `-20`
- `0`
- `39`
- `40`
- `100`
- `120`

## Example 2 - Quantity

~~~python
quantity = int(input("Quantity: "))

if quantity <= 0:
    print("Quantity must be greater than zero")
else:
    print("Order accepted")
~~~

## Mini exercise - Age validator

Ask for an age.

For this exercise, accept ages from 0 to 120.

If the age is outside that range, display:

~~~
Invalid age
~~~

Otherwise display:

~~~

~~~

## Important

This code **detects** invalid input.

Later, when you study loops, you can make the program repeatedly ask until valid input is entered.
