# Ranges and chained comparisons

Suppose a valid mark must be between 0 and 100.

We could write:

~~~python
if mark >= 0 and mark <= 100:
~~~

Python also allows:

~~~python
if 0 <= mark <= 100:
~~~

This is called a chained comparison.

## Example 1 - Valid mark

Create **04_ranges.py**.

~~~python
mark = int(input("Enter mark: "))

if 0 <= mark <= 100:
    print("Valid mark")
else:
    print("Invalid mark")
~~~

Test:

- `-1`
- `0`
- `50`
- `100`
- `101`

## Example 2 - Cinema child ticket

A child ticket is for ages 5 through 15 inclusive.

~~~python
age = int(input("Age: "))

if 5 <= age <= 15:
    print("Child ticket")
else:
    print("Another ticket type")
~~~
