# Separate `if` statements or `elif`?

This is an important design decision.

## Example 1 - Independent questions

Create **02_independent_if.py**.

~~~python
number = int(input("Enter a number: "))

if number > 0:
    print("Positive")

if number % 2 == 0:
    print("Even")
~~~

If the user enters `8`, both messages are printed.

Why?

The two conditions are independent.

## Example 2 - One classification

~~~python
age = int(input("Enter age: "))

if age < 13:
    print("Child")
elif age < 18:
    print("Teenager")
else:
    print("Adult")
~~~

Only one classification should be displayed, so `elif` is appropriate.
