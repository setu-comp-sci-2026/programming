# `if-else` - Solutions

## Pass or fail

~~~python
mark = int(input("Enter your mark: "))

if mark >= 40:
    print("Pass")
else:
    print("Fail")
~~~

Expected results:

| mark | output |
| --- | --- |
| 20 | Fail |
| 39 | Fail |
| 40 | Pass |
| 41 | Pass |
| 90 | Pass |

## Even or odd

~~~python
number = int(input("Enter a whole number: "))

if number % 2 == 0:
    print("Even")
else:
    print("Odd")
~~~

`number % 2` gives the remainder after division by 2.

An even number has a remainder of `0`.
