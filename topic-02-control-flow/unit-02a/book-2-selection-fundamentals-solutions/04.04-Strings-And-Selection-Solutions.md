# Strings and selection - Solutions

## Password example

~~~python
password = input("Enter the password: ")

if password == "python":
    print("Access granted")
else:
    print("Access denied")
~~~

Only:

~~~
python
~~~

matches exactly.

`Python` and `PYTHON` do not match because string comparisons are case-sensitive.

## Improved yes/no example

~~~python
answer = input("Would you like to continue? ").lower()

if answer == "yes":
    print("Continuing...")
else:
    print("Stopping...")
~~~

Using `.lower()` means inputs such as:

~~~
YES
Yes
yes
~~~

all become:

~~~
yes
~~~

before the comparison.
