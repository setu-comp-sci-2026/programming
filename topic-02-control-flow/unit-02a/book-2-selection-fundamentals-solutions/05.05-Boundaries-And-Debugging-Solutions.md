# Boundaries and debugging - Solutions

## Theme park ride

The correct condition is:

~~~python
if height >= 120:
~~~

because someone who is exactly 120 cm tall is allowed.

## Program A

Incorrect:

~~~python
if age = 18:
~~~

Correct:

~~~python
if age == 18:
    print("You are 18")
~~~

## Program B

Incorrect:

~~~python
if temperature < 5
~~~

Correct:

~~~python
if temperature < 5:
    print("Cold day")
~~~

## Program C

Corrected:

~~~python
mark = int(input("Mark: "))

if mark >= 40:
    print("Pass")
else:
    print("Fail")
~~~

## Program D

Incorrect:

~~~python
if age < 15:
~~~

Correct:

~~~python
age = int(input("Age: "))

if age <= 15:
    print("Child ticket")
else:
    print("Standard ticket")
~~~

## Reflection

Testing just below, exactly on, and just above a boundary helps us identify mistakes such as using:

~~~python
>
~~~

when we should use:

~~~python
>=
~~~
