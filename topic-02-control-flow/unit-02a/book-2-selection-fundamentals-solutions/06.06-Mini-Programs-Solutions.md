# Mini programs - Solutions

## Exercise 1 - Cinema entry

~~~python
age = int(input("Enter your age: "))

if age >= 16:
    print("Entry allowed")
else:
    print("Sorry, you are too young")
~~~

## Exercise 2 - Temperature warning

~~~python
temperature = float(input("Enter the temperature: "))

if temperature < 0:
    print("Warning: icy conditions")
else:
    print("No ice warning")
~~~

## Exercise 3 - Larger number

~~~python
first = float(input("First number: "))
second = float(input("Second number: "))

if first > second:
    print(first, "is larger")
else:
    print(second, "is larger")
~~~

## Exercise 4 - Discount

~~~python
cost = float(input("Order cost: €"))

if cost >= 100:
    discount = cost * 0.10
    final_price = cost - discount
else:
    final_price = cost

print("Final price: €", final_price)
~~~

## Exercise 5 - Username check

~~~python
username = input("Enter username: ")

~~~

## Challenge - Number detective

~~~python
number = int(input("Enter a whole number: "))

if number > 0:
    print("Positive")
else:
    print("Not positive")

if number % 2 == 0:
    print("Even")
else:
    print("Odd")
~~~
