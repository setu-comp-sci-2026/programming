# Boolean expressions - Solutions

## Example 1

For:

~~~python
age = 18

print(age >= 18)
print(age < 18)
print(age == 18)
~~~

the output is:

~~~
True
False
True
~~~

If:

~~~python
age = 16
~~~

the output becomes:

~~~
False
True
False
~~~

## Example 2

~~~python
number = 10

print(number == 10)
print(number != 10)
print(number > 5)
print(number < 5)
print(number >= 10)
print(number <= 9)
~~~

Output:

~~~
True
False
True
False
True
False
~~~

## Mini exercise

~~~python
temperature = 12
password = "python"

print(temperature < 10)
print(temperature >= 12)
print(password == "python")
print(password != "java")
~~~

Output:

~~~
False
True
True
True
~~~

## Key point

~~~python
age = 18
~~~

assigns the value `18`.

~~~python
age == 18
~~~

asks whether `age` is equal to `18`.
