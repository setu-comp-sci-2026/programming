# Your first `if` statement

An `if` statement allows a program to run some code only when a condition is `True`.

## Example 1 - Cinema age check

Create **02_first_if.py**.

~~~python
age = int(input("Enter your age: "))

if age >= 18:
    print("You can watch the film")

print("Enjoy your visit to the cinema")
~~~

Run the program several times.

Try:

- `17`
- `18`
- `25`

## What happens?

The line:

~~~python
if age >= 18:
~~~

asks a question.

If the answer is `True`, Python executes the indented line.

If it is `False`, Python skips the indented line.

## Indentation matters

This:

~~~python
if age >= 18:
    print("You can watch the film")
~~~

is different from:

~~~python
if age >= 18:
print("You can watch the film")
~~~

The second example produces an error because the body of the `if` statement must be indented.
