# Boolean expressions

Selection is based on a question that Python can answer with either:

~~~
True
False
~~~

These are Boolean values.

## Example 1 - Comparing numbers

Create a file called **01_boolean_expressions.py**.

Enter:

~~~python
age = 18

print(age >= 18)
print(age < 18)
print(age == 18)
~~~

Run the program.

What output do you expect?

Now change:

~~~python
age = 18
~~~

to:

~~~python
age = 16
~~~

Run the program again.

## Comparison operators

| Operator | Meaning |
| --- | --- |
| `==` | equal to |
| `!=` | not equal to |
| `>` | greater than |
| `<` | less than |
| `>=` | greater than or equal to |
| `<=` | less than or equal to |

## Example 2 - Try the operators

Add:

~~~python
number = 10

print(number == 10)
print(number != 10)
print(number > 5)
print(number < 5)
print(number >= 10)
print(number <= 9)
~~~

Before running the program, predict whether each line will display `True` or `False`.

Then run it and check your answers.

## Mini exercise

Create variables:

~~~python
temperature = 12
password = "python"
~~~

Write Boolean expressions to answer:

1. Is the temperature below 10?
2. Is the temperature at least 12?
3. Is the password equal to `"python"`?
4. Is the password not equal to `"java"`?

## Important

Do not confuse:

~~~python
age = 18
~~~

with:

~~~python
age == 18
~~~

`=` assigns a value.

`==` compares two values.
