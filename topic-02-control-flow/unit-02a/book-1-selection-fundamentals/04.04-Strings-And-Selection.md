# Strings and selection

Conditions do not have to compare numbers.

We can also compare strings.

## Example 1 - Password

Create **04_strings.py**.

~~~python
password = input("Enter the password: ")

if password == "python":
    print("Access granted")
else:
    print("Access denied")
~~~

Test:

~~~
python
Python
PYTHON
java
~~~

What do you notice?

Python string comparisons are case-sensitive.

## Example 2 - Yes or no

~~~python
answer = input("Would you like to continue? ")

if answer == "yes":
    print("Continuing...")
else:
    print("Stopping...")
~~~

Try entering:

- `yes`
- `no`
- `Yes`
- `YES`

## Improvement

Change the input line to:

~~~python
answer = input("Would you like to continue? ").lower()
~~~

Test again.
