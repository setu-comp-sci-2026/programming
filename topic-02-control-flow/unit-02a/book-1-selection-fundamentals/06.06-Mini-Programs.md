# Mini programs

Complete each program in a separate Python file.

## Exercise 1 - Cinema entry

Ask the user for their age.

People aged 16 or over may enter.

Display either:

~~~
Entry allowed
~~~

or:

~~~
Sorry, you are too young
~~~

Test ages `15`, `16`, and `17`.

## Exercise 2 - Temperature warning

Ask for the temperature.

If the temperature is below `0`, display:

~~~
Warning: icy conditions
~~~

Otherwise display:

~~~
No ice warning
~~~

## Exercise 3 - Larger number

Ask the user for two numbers.

Display which number is larger.

For now, you may assume the two numbers are different.

Example:

~~~
First number: 12
Second number: 8
12 is larger
~~~

## Exercise 4 - Discount

Ask for the cost of an order.

If the cost is at least €100, apply a 10% discount.

Otherwise, keep the original price.

Display the final price.

Hint:

~~~python
discount = cost * 0.10
~~~

## Exercise 5 - Username check

Ask the user for a username.

If the username is `"student"`, display:

~~~
Welcome
~~~

Otherwise display:

~~~
Unknown user
~~~

## Challenge - Number detective

Ask the user for a whole number.

Display whether it is:

- positive or not positive

Then also display whether it is:

- even or odd

You will need **two separate `if` statements**.
