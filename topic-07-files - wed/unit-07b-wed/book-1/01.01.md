# JSON: creating a small knowledge file

In Monday's lab, we saved Python data as JSON. Today we will **load questions and recommendations** from a JSON file.

Create a file called **knowledge.json** and enter:

```json
{
  "questions": [
    {"key": "power_on", "text": "Does the computer turn on?"},
    {"key": "display_on", "text": "Is there an image on the screen?"}
  ],
  "rules": [
    {"when": {"power_on": "no"}, "advice": "Check the power cable and socket."},
    {"when": {"power_on": "yes", "display_on": "no"}, "advice": "Check the monitor connection."}
  ]
}
```

## Read the JSON file

Create **01_json_knowledge.py** in the same working folder:

```python
import json

with open("knowledge.json", "r", encoding="utf-8") as file:
    knowledge = json.load(file)

print(knowledge)
print("First question:", knowledge["questions"][0]["text"])
print("First recommendation:", knowledge["rules"][0]["advice"])
```

Run your program. json.load() converts the JSON object into a Python dictionary containing two lists.
