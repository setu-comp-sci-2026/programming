# Organising your program with `main()`

As our programs become longer, it helps to keep the starting sequence in one function.

## Step 1: Write a simple `main()`

Create **04_introducing_main.py**:

```python
def display_menu():
    print("PC Troubleshooter")
    print("1. Start troubleshooting")
    print("2. Exit")


def main():
    display_menu()
    print("Ready to begin!")


main()
```

Run it. `main()` is an ordinary function; its name is a programming convention.

## Step 2: Add a menu loop

Replace `main()` with:

```python
def main():
    choice = ""

    while choice != "2":
        display_menu()
        choice = input("Choose an option: ")

        if choice == "1":
            print("Starting troubleshooting...")
        elif choice != "2":
            print("Invalid choice")
```

## Step 3: Use the standard starting point

Replace the final `main()` call with:

```python
if __name__ == "__main__":
    main()
```

When the file is run directly, Python sets `__name__` to `"__main__"`. When it is imported into another program, the menu will not start automatically.
