# Challenges

Try the guided work and exercises first.

## Challenge 1 — More specific rules

Add `cable_connected` to the PC Troubleshooter knowledge file. Write a rule for a computer that will not power on **and** has its cable disconnected.

Place the new rule before the general `power_on = no` rule. Test both recommendations. Explain why rule order matters.

## Challenge 2 — View saved consultations

Add a `view_history()` function that displays each consultation's timestamp, answers and recommendation. Call it from a menu option.

If the history file does not exist, display `No consultations saved yet.`

## Challenge 3 — Change the working directory

Run your PC Troubleshooter from the **parent folder** using a terminal command such as:

```text
python PC_Troubleshooter/troubleshooter.py
```

Does the JSON file still load? Explain how `Path(__file__).resolve().parent` helps.

## Challenge 4 — Test a broken knowledge file

Make a **copy** of `knowledge.json`. Remove a comma from the copy and try loading it.

- What exception name appears?
- Does the error tell you where the problem is?
- Restore the valid JSON before continuing.

You do **not** need to handle the exception yet; that is a Week 8 topic.

## Challenge 5 — Expand the expert system

Add a new symptom such as `internet_on` and at least two recommendations that use it. Plan the rules before coding.

Create a test table with the answers, expected recommendation and actual recommendation. Include a case that should fall through to the default advice.
