# Saving structured data with JSON

Create a file called **03_json_basics.py**.

Plain text works well for notes, but our Dog Day Care records have several related values. JSON lets us store a **list of dictionaries**.

## Step 1 — Create some records

~~~python
import json

dogs = [
    {"name": "Buddy", "age": 4},
    {"name": "Luna", "age": 2}
]
~~~

## Step 2 — Save the records

~~~python
with open("dogs.json", "w", encoding="utf-8") as file:
    json.dump(dogs, file, indent=4)
~~~

Run the program and inspect `dogs.json`. What does `indent=4` change?

## Step 3 — Load the records

~~~python
with open("dogs.json", "r", encoding="utf-8") as file:
    loaded_dogs = json.load(file)

print(loaded_dogs)
print(loaded_dogs[0]["name"])
~~~

- `json.dump()` saves Python data to a file.
- `json.load()` reads JSON from a file and reconstructs Python data.
