## Journal — append and read

~~~python
note = input("Enter a journal note: ").strip()
while note == "":
    note = input("Note cannot be blank. Try again: ").strip()

with open("journal.txt", "a", encoding="utf-8") as file:
    file.write(note + "\n")

with open("journal.txt", "r", encoding="utf-8") as file:
    print(file.read())
~~~

## Exercise 1 — Persistent shopping list

~~~python
item = input("Shopping item: ").strip()
while item == "":
    item = input("Please enter an item: ").strip()

with open("shopping.txt", "a", encoding="utf-8") as file:
    file.write(item + "\n")

print("Shopping list:")
with open("shopping.txt", "r", encoding="utf-8") as file:
    for line in file:
        print("-", line.strip())
~~~

## Exercise 2 — Save and load books

~~~python
import json

books = [
    {"title": "Jaws", "author": "Peter Benchley", "year": 1974},
    {"title": "The Hobbit", "author": "J. R. R. Tolkien", "year": 1937},
    {"title": "Matilda", "author": "Roald Dahl", "year": 1988}
]

with open("books.json", "w", encoding="utf-8") as file:
    json.dump(books, file, indent=4)

with open("books.json", "r", encoding="utf-8") as file:
    books = json.load(file)

for book in books:
    print(f"{book['title']} by {book['author']} ({book['year']})")

books.append({"title": "Dune", "author": "Frank Herbert", "year": 1965})
with open("books.json", "w", encoding="utf-8") as file:
    json.dump(books, file, indent=4)
~~~

## Exercise 4 — Persistent movie manager (functions to add)

~~~python
import json

def save_movies(movies):
    with open("movies.json", "w", encoding="utf-8") as file:
        json.dump(movies, file, indent=4)

def load_movies():
    with open("movies.json", "r", encoding="utf-8") as file:
        return json.load(file)
~~~

Create `movies.json` once from your starter movie list using `save_movies(movies)`. On later runs, use `movies = load_movies()` before the menu loop. Call `save_movies(movies)` after a successful add, update or delete.

## Challenge 1 — Journal menu

~~~python
def get_choice():
    choice = input("A=Add, V=View, Q=Quit: ").strip().upper()
    while choice not in ["A", "V", "Q"]:
        choice = input("Choose A, V or Q: ").strip().upper()
    return choice

while True:
    choice = get_choice()
    if choice == "A":
        note = input("Note: ").strip()
        while note == "":
            note = input("Note cannot be blank: ").strip()
        with open("journal.txt", "a", encoding="utf-8") as file:
            file.write(note + "\n")
    elif choice == "V":
        with open("journal.txt", "a", encoding="utf-8"):
            pass  # Create the file if this is the first run
        with open("journal.txt", "r", encoding="utf-8") as file:
            print(file.read())
    else:
        break
~~~

## Challenge 3 — Reusable validation functions

~~~python
def get_age():
    age = int(input("Age (0 to 25): "))
    while age < 0 or age > 25:
        age = int(input("Enter an age from 0 to 25: "))
    return age

def get_name():
    name = input("Dog's name: ").strip()
    while name == "":
        name = input("Name cannot be blank: ").strip()
    return name
~~~

**Reminder:** Numeric validation here checks the **range**, not whether the input is numeric. Handling text entered for a number is covered with exceptions in Week 8.
