# Challenges

These are optional extensions. Complete the guided lab and exercises first.

## Challenge 1 — A journal with a menu

Create a menu-driven journal:

- `A` — add a note
- `V` — view all notes
- `Q` — quit

Validate the menu choice using `.strip().upper()` and a loop. Use `"a"` to keep earlier entries.

## Challenge 2 — Dog Day Care with a persistent menu

Extend the Dog Day Care program to allow users to:

1. Add a dog (with name and age validation).
2. View all dogs.
3. Search for a dog by name.
4. Exit.

Load the saved list at the start and save changes after adding a dog. Assume `dogs.json` has already been created.

## Challenge 3 — Improve your validation

Add a function called `get_age()` that returns a valid age from 0 to 25. Reuse it whenever the program asks for a dog's age.

Then add a second function called `get_name()` that rejects blank names.

**Think about:** Why is it useful to keep validation in separate functions?

## Challenge 4 — Predict the data loss

Using the following code:

~~~python
with open("journal.txt", "w", encoding="utf-8") as file:
    file.write("Today's note\n")
~~~

Explain what happens if the file already contains ten notes. Change the code so earlier notes are kept.

## Challenge 5 — Choose your own theme

Adapt the JSON persistence example to a different list of dictionaries: games, books, planets, songs or student records. Use the same **load → change → save** pattern.
