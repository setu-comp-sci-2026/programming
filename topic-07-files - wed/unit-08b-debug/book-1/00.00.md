# Week 8 Lab — Importing Python Modules

## Learning outcomes
By the end of this lab, you should be able to:
- explain what a Python module is and why we use `import`;
- use functions from the Python standard library;
- distinguish `import module` from `from module import function`;
- create your own `.py` module and call it from another file;
- investigate import mistakes and debug a function in another file.
