# Code from Class: Import Your Own Python File

A module can be **your own Python file**. We will separate reusable calculations from the main program.

## Step 1 — Create two files
Create this folder structure:

```text
CalculatorProject/
    main.py
    calculator.py
```

In `calculator.py`, write:

```python
def add(a, b):
    return a + b


def divide(a, b):
    return a / b
```

In `main.py`, write:

```python
import calculator

answer = calculator.add(10, 5)
print("Total:", answer)
```

Run **`main.py`**. The expected output is `Total: 15`.

## Step 2 — Import one function
Replace the code in `main.py` with:

```python
from calculator import add

answer = add(10, 5)
print("Total:", answer)
```

## Step 3 — Add another function
Add `multiply(a, b)` to `calculator.py` and call it from `main.py`. Test with `4` and `6`.

## Step 4 — Debug across files
1. Set a breakpoint on the function call in `main.py`.
2. Start debugging with **F5**.
3. Use **F11 (Step Into)** to enter the function in `calculator.py`.
4. Inspect `a` and `b` in the Variables panel.
5. Use **F10 (Step Over)** and observe the returned value.

**Question:** Does importing a function copy its source code into `main.py`, or does the function remain defined in `calculator.py`?
