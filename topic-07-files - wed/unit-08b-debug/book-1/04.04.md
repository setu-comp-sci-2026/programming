# 04 — Code from Class: Import Mistakes and Debugging

## Example 1 — Misspelt module name
With `calculator.py` in the same folder, try:

```python
import calculater

print(calculater.add(2, 3))
```

**Predict:** What exception do you expect? Run the program and read the traceback. Correct the spelling.

## Example 2 — Function does not exist

```python
import calculator

print(calculator.subtract(3, 1))
```

The module exists, but does it contain `subtract`? What exception is raised? Add the function or change the call.

## Example 3 — A logic error inside another file
Create `pricing.py`:

```python
def discounted_price(price, discount_percent):
    discount = price * discount_percent / 100
    return price + discount  # Deliberate logic error
```

Create `main.py` in the same folder:

```python
import pricing

price = 50
discount_percent = 20
final_price = pricing.discounted_price(price, discount_percent)
print("Price after discount:", final_price)
```

**Predict:** A 20% discount on €50 should give **€40**. What does this program print?

### Investigate using the VS Code debugger
1. Set a breakpoint on `final_price = ...` in `main.py`.
2. Press **F5**, then **F11** to step into `pricing.py`.
3. Inspect `price`, `discount_percent` and `discount`.
4. Step through the return statement and identify the logic error.
5. Fix it and run the program again.

**Important:** A logic error can produce an incorrect answer **without raising an exception**.

## File-naming caution
Avoid naming your own files `random.py`, `json.py` or `math.py`. They may hide the standard-library modules you meant to import.
