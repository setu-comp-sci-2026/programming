# 06 — Exercises

Complete these **after** Code from Class. Create a separate folder for each exercise involving multiple files. Predict the output before running your code.

## Exercise 1 — A different die
Create `dice_game.py`. Import `random` and simulate rolling **two six-sided dice**. Display both values and their total.

## Exercise 2 — Maths helper
Using `import math`, ask the user for a positive number and display its square root. Test with `49`. Then deliberately enter a negative number and observe what happens. **Extension:** handle invalid numeric input with `try`/`except`.

## Exercise 3 — Extend the calculator
Create `calculator.py` and `main.py`. Put four functions in the module: `add`, `subtract`, `multiply`, `divide`. From `main.py`, call each function using `import calculator`. Use `12` and `3` as test values.

## Exercise 4 — Import one function
Change Exercise 3 so that `main.py` uses `from calculator import multiply`. Call `multiply(7, 8)` without writing `calculator.`.

## Exercise 5 — Debug an imported function
Use the faulty `pricing.py` example from Section 04. Set a breakpoint in `main.py`, step into the function with F11, inspect the variables and correct the calculation. Record the **expected**, **actual** and **corrected** results for a price of €80 and a 25% discount.

## Exercise 6 — Read an import traceback
In a fresh project folder, create `messages.py` with a function `welcome()` that prints `Welcome!`. In `main.py`, deliberately write `import mesages` and run it. Record the exception type. Fix the spelling and call the function. Then deliberately call `messages.goodbye()` without defining it; record the new exception type.

## Reflection
Which error was easier to diagnose: a misspelt module name or an incorrect calculation in an imported function? Explain why.
