# Lab 6B — Create, Read, Update and Delete

**Focus:** using functions to manage records in a list of dictionaries.

## Core 1 — Plan the application

We want a simple **Dog Day Care Manager**. Each dog has an ID, name, breed and age.

Before writing code, think about what each operation needs:

| Operation | What should it do? | What could go wrong? |
|---|---|---|
| Create | Add a new dog | An ID already exists |
| Read | Display or find a dog | The list is empty |
| Update | Change a dog's details | The ID is not found |
| Delete | Remove a dog | The ID is not found |

**Discuss:** Why might an ID be more useful than searching by name?
