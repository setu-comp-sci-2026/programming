# Challenges

These are **not compulsory**. Try them only if you have time or would like extra practice.

## Challenge 1 – Display Summary
Add a summary showing total dogs, dogs under 2, and dogs aged 8 or older.

## Challenge 2 – Search by Breed
Ask for a breed and display **all** matching dogs, ignoring case. Think about why you should not return after the first match.

## Challenge 3 – Keep Existing Values
Improve Update so pressing Enter keeps the current value.

## Challenge 4 – Create Your Own Manager
Build another small CRUD manager for books, games, films, players, recipes, exercises or products. Include Create, Read, Update, Delete and Search. Do not simply rename the Dog Day Care variables.

## 11. One Important Limitation
Add a dog, exit, and run the program again. The new dog is gone because the list exists only while the program is running.
