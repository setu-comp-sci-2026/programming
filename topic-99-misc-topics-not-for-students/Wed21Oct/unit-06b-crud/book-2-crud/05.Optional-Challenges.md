# Week 6 — Optional Challenges

These are **not compulsory**. Try them only if you have time or would like extra practice.

## Challenge 1 — Search by name

Add a function to the Dog Day Care Manager that searches by dog name. What happens if two dogs have the same name? Could you make the search case-insensitive?

## Challenge 2 — Another field

Add a `vaccinated` field (`True` or `False`) to each dog. Update the display and create functions.

## Challenge 3 — Search questions by keyword

Write a function that displays all questions containing a word supplied by the user. Try searching for `power`.

## Challenge 4 — More than one condition

Suppose a recommendation should be made when:

- the computer does **not** turn on, **and**
- the cable **is** connected, **and**
- the power light **is off**.

Write this rule in plain English. Then sketch a dictionary that could store all three conditions. **You don't need to write code to evaluate it yet.**

## Challenge 5 — Plan your own expert system

Choose an area you know something about, such as plants, games, sport, cooking or technology. Plan:

- five questions
- three possible recommendations
- three IF/THEN rules

You might find these ideas useful when planning Assignment 2.

## Looking ahead

This week we store the knowledge in Python lists and dictionaries. Next week we'll move that knowledge into a JSON file, then gradually add error handling, classes and a rule engine.
