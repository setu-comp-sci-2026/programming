# 11. Persistent Knowledge – JSON

Eventually, your Knowledge Base should be stored outside your Python program.

JSON is recommended.

For example:

```json
{
    "questions": [
        {
            "id": "Q1",
            "text": "Does the computer power on?",
            "type": "yes_no",
            "category": "power"
        },
        {
            "id": "Q2",
            "text": "Are any power lights visible?",
            "type": "yes_no",
            "category": "power"
        }
    ],
    "recommendations": [
        {
            "id": "R1",
            "title": "Possible Power Supply Problem",
            "description": "Check the computer's power supply."
        }
    ],
    "rules": [
        {
            "id": "RULE1",
            "conditions": {
                "Q1": "no",
                "Q2": "yes"
            },
            "recommendation": "R1"
        }
    ]
}
```

When the program starts, it should load its expert knowledge from the Knowledge Base.
