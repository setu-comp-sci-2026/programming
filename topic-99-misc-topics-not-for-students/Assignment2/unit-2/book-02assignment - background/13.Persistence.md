# 13. Persistence

Changes made to the Knowledge Base must persist after the program closes.

For example, if an administrator:

1. adds a new recommendation
2. saves the Knowledge Base
3. exits the program
4. starts the program again

the new recommendation should still exist.

Your program should therefore be capable of:

```text
JSON File
    ↓
Load
    ↓
Python Program
    ↓
Modify Knowledge
    ↓
Save
    ↓
JSON File
```
