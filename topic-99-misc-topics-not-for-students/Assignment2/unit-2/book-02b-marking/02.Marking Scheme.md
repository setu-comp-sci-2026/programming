# 02. Marking Scheme

This project is worth **60% of the module**.

| Assessment Area | Marks |
| --- | ---: |
| Expert system functionality | 10 |
| **Knowledge Base design and quality** | **12** |
| **Rules and inference engine** | **13** |
| Data structures and CRUD | 10 |
| Files, JSON and persistence | 8 |
| Classes and Object-Oriented design | 10 |
| Exception handling and testing | 8 |
| Code quality and project structure | 6 |
| Development process/checkpoints | 5 |
| Reflection Document | 4 |
| Video recording | 4 |
| Extras | 10 |
| **Total (Before interview multiplier)** | **100** |


The interview mark will be used as a multiplier for the final mark of the assignment.

So if you you achieve a total mark of 100% before an interview, and your interview mark is 100%, then your final mark will be 100% for this assignment..

If you achieve a total mark of 70% before an interview, and your interview mark is 50%, then your final mark will be 35% for this assignment.

If you are **not** invited for an interview, the mark for the interview will be 100% (no multiplier).
