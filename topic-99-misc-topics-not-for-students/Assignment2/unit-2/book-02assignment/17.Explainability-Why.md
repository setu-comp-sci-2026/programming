# 17. Explainability – Why?

A good expert system should be capable of explaining its reasoning.

Your program should not simply output:

```text
Possible Power Supply Problem
```

Instead, it should provide information such as:

```text
================================
        RECOMMENDATION
================================

Possible Power Supply Problem

WHY?

You told the system that:

✓ The computer does not power on
✓ Power lights are visible
✓ The fan does not start

These answers matched rules associated
with a possible power supply problem.
```

The explanation should be generated from the rules and answers used by your system rather than being simply a generic message.
