# 15. Matching Rules

Consider the following rule:

```text
RULE1

Q1 = no
Q2 = yes
Q3 = no

Recommendation = R1
```

and the user answers:

```text
Q1 = no
Q2 = yes
Q3 = no
```

All three conditions match.

The inference engine should therefore recognise that this rule applies.

You will need to think carefully about:

- how answers are stored
- how conditions are represented
- how rules are examined
- how matching rules are identified

There is no single required algorithm.

Designing this part of the system is an important part of the challenge.
