# 12. Knowledge Base Management

Your application must allow an authorised user to manage the Knowledge Base.

For example:

```text
================================
       KNOWLEDGE BASE
================================

1. Manage Questions
2. Manage Recommendations
3. Manage Rules
0. Return to Main Menu
```

The system should demonstrate **CRUD**:

- Create
- Read
- Update
- Delete

For example:

```text
QUESTION MANAGEMENT

1. View Questions
2. Add Question
3. Edit Question
4. Delete Question
0. Return
```

You do not have to create an extremely complicated management interface.

The aim is to demonstrate that the knowledge in your system can be maintained.
