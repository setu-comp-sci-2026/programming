# 20. Inheritance

Your project must demonstrate an appropriate use of inheritance.

Questions provide one possible opportunity.

For example:

```text
                  Question
                     |
          +----------+----------+
          |          |          |
       YesNo       Choice     Numeric
      Question     Question    Question
```

All questions may contain common information such as:

- ID
- question text
- category

but different question types may collect and validate answers differently.

For example:

```python
class Question:
    ...


class YesNoQuestion(Question):
    ...


class ChoiceQuestion(Question):
    ...


class NumericQuestion(Question):
    ...
```

Inheritance should represent a genuine relationship within your program rather than being added simply to meet the assignment requirements.
