# 6. Recommendations

Your system should contain a range of possible recommendations or conclusions.

As a guide, you should have approximately:

**8–10 meaningful recommendations.**

For example, a computer troubleshooting expert might identify:

```text
R1 – Possible battery problem
R2 – Possible power supply problem
R3 – Possible display problem
R4 – Possible overheating
R5 – Possible storage problem
R6 – Possible operating system problem
R7 – Possible network problem
R8 – Possible peripheral problem
```

Each recommendation should contain sufficient information to be useful to the user.
