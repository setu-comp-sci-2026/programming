# PC Troubleshooting Expert – Example

This is a deliberately small teaching example for Assignment 2.

## Files

- `main.py` – menus and program entry point
- `expert_system.py` – consultation and inference
- `knowledge_base.py` – loads, saves and manages knowledge
- `question.py` – base Question class and subclasses
- `rule.py` – represents and evaluates a rule
- `recommendation.py` – represents a recommendation
- `data/knowledge_base.json` – the expert knowledge

## Run

Open the folder in VS Code and run:

```text
python main.py
```

The example is intentionally smaller than the final assignment requirements. It demonstrates the architecture without giving students a complete assignment solution.
