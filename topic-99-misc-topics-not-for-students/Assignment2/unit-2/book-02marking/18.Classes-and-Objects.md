# 18. Classes and Objects

As you learn Object-Oriented Programming, appropriate parts of your system should be represented using classes and objects.

Possible classes include:

```text
KnowledgeBase
ExpertSystem
Question
Rule
Recommendation
```

You do not have to use these exact classes.

Your classes should have clear responsibilities.

For example:

```python
class Recommendation:

    def __init__(self, recommendation_id, title, description):
        self.recommendation_id = recommendation_id
        self.title = title
        self.description = description

    def display(self):
        print(self.title)
        print(self.description)
```

Your final system should demonstrate appropriate understanding of:

- classes
- objects
- attributes
- constructors
- methods
- parameters
- return values
- interaction between objects
