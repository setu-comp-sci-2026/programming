# 14. The Inference Engine

The **Inference Engine** is the part of your program that applies the rules in the Knowledge Base.

It should:

1. collect relevant answers from the user
2. examine the rules
3. compare rule conditions with user answers
4. determine which rules match
5. identify suitable recommendations
6. provide a result

The important point is that the inference engine should be reasonably **general**.

It should not contain a separate hard-coded `if` statement for every individual rule in your Knowledge Base.
