# 21. Polymorphism

Different question objects might all provide an `ask()` method.

For example:

```python
for question in questions:
    answer = question.ask()
```

The program can call:

```python
question.ask()
```

regardless of whether the object is a:

```text
YesNoQuestion
ChoiceQuestion
NumericQuestion
```

Each type of question can behave differently.

This provides an opportunity to demonstrate **polymorphism**.
