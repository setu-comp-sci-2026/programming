# 25. Development Milestones

You are not expected to build the complete system immediately.

The project will develop alongside the programming concepts covered in class.

## Milestone 1 – Become the Expert

Choose your topic.

Research and identify:

- the problem your system will address
- who will use it
- the type of advice it will provide
- possible questions
- possible conclusions
- initial rules

Create an initial Knowledge Base **on paper or in a document before concentrating on Python**.

## Milestone 2 – Rule-Based Prototype

Build a small working prototype using:

- input
- selection
- functions

At this stage, some rules may still be contained directly in the Python code.

The objective is to demonstrate that the idea works.

## Milestone 3 – Knowledge as Data

After learning data structures:

- represent questions using suitable data structures
- represent recommendations using suitable data structures
- begin representing rules as data
- process collections of knowledge

This is an important transition:

> **Your program should begin to process rules rather than simply contain rules.**

## Milestone 4 – Knowledge Base Management

Introduce CRUD functionality.

Demonstrate that you can:

- Create knowledge
- Read knowledge
- Update knowledge
- Delete knowledge

## Milestone 5 – Persistent Knowledge Base

Move the Knowledge Base into JSON.

Your program should:

- load knowledge
- modify knowledge
- save knowledge
- reload saved knowledge

## Milestone 6 – Objects

Introduce appropriate classes and objects.

Move suitable data and behaviour into classes.

Be prepared to explain:

- why you created each class
- what responsibility it has
- how objects interact

## Milestone 7 – Inheritance and Polymorphism

Introduce an appropriate inheritance hierarchy.

Demonstrate that different specialised objects can be treated through a common interface.

## Milestone 8 – Final Expert System

Complete:

- consultation
- inference
- explanation
- Knowledge Base management
- persistence
- validation
- testing

Prepare for your final demonstration.
