# 6. Extras

The prescribed parts of the assignment make up 90% of your mark. 

It is up to you to add additional features to improve your mark. There are 10% available for extras that you can choose to add.

For example:

- using inheritance and polymorphism (structural improvements) 
- adding extra features (functional improvements)

Ask us if you are unsure. 

> **Important:** If you are adding any features/functionality, please make sure you explain what it is and how you implemented it in your reflection document.

> **Important:** You must attempt at least the minimum requirements of the specification before adding any extra features.
