## Exercise 5 – Count Spaces

```python
sentence = input("Enter a sentence: ")
spaces = 0

for character in sentence:
    if character == " ":
        spaces = spaces + 1

print("Spaces:", spaces)
```

## Exercise 6 – Count Vowels

```python
sentence = input("Enter a sentence: ")
vowels = 0

for character in sentence:
    if (character.lower() == "a" or
        character.lower() == "e" or
        character.lower() == "i" or
        character.lower() == "o" or
        character.lower() == "u"):
        vowels = vowels + 1

print("Vowels:", vowels)
```
