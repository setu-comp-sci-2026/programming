# Exercises

Complete these after the guided lab.

## Exercise 1 - Number classification

Ask for a number.

Display whether it is:

- negative
- zero
- positive

Use `if-elif-else`.

## Exercise 2 - Largest of three

Ask for three different numbers.

Display the largest.

## Exercise 3 - Delivery charge

Ask for an order total.

Use:

| Order total | Delivery |
| --- | ---: |
| €50 or more | Free |
| €25 to €49.99 | €4 |
| Below €25 | €7 |

Display the delivery charge.

## Exercise 4 - Login

Store:

~~~python
correct_username = "student"
correct_password = "python123"
~~~

Ask the user for a username and password.

Access is granted only when **both** are correct.

## Exercise 5 - Weekend discount

Ask for the day of the week and the customer's age.

A discount applies when:

- the day is `"saturday"` or `"sunday"`
- and the customer is under 18

Display whether the discount applies.

## Exercise 6 - Valid percentage

Ask for a percentage.

If it is outside 0–100, display `Invalid`.

Otherwise classify it as:

- `High` for 70–100
- `Medium` for 40–69
- `Low` for 0–39

## Exercise 7 - Leap-year starter

For this simplified exercise, ask for a year.

If it is divisible by 4, display:

~~~
Possible leap year
~~~

Otherwise display:

~~~
Not a leap year
~~~

Use `%`.

> Note: the complete leap-year rule has additional conditions. This exercise is only practising selection and modulo.

## Challenge - Theme park ticket

Build a program that asks for:

- age
- height
- whether the customer is a student

Rules:

1. Customers must be at least 120 cm tall to enter the main ride area.
2. If they are too short, display an appropriate message.
3. If they are tall enough:
   - under 16: €12
   - 16 to 64: €20
   - 65+: €14
4. Students aged 16 to 64 receive a €3 discount.

Display the final price.

Test boundary values carefully.
