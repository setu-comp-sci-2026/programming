# Ranges and chained comparisons - Solutions

## Valid mark

~~~python
mark = int(input("Enter mark: "))

if 0 <= mark <= 100:
    print("Valid mark")
else:
    print("Invalid mark")
~~~

Expected results:

| mark | result |
| --- | --- |
| -1 | Invalid |
| 0 | Valid |
| 50 | Valid |
| 100 | Valid |
| 101 | Invalid |

## Comfortable temperature

~~~python
temperature = float(input("Enter temperature: "))

if 18 <= temperature <= 22:
    print("Comfortable")
else:
    print("Outside comfort range")
~~~

Important tests include:

~~~
17
18
22
23
~~~
