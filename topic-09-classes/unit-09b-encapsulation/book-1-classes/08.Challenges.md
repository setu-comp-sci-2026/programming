## Challenge 1 — Contact Book

Build a contact book using two classes: `Contact` and `ContactBook`.

**Contact class:**
- Properties: `name`, `phone`, `email` (all validated)
- Phone: must be digits only, 7-15 characters
- Email: must contain `@` and a domain with `.`
- `__str__` showing all contact info

**ContactBook class:**
- Stores a list of `Contact` objects
- Methods:
  - `add(contact)` — add a contact (reject duplicate phone/email)
  - `remove(name)` — remove by name
  - `find(search)` — return contacts matching search in name, phone, or email
  - `list_all()` — print all contacts sorted by name
  - `save(filename)` — save all contacts to a CSV file
  - `load(filename)` — load contacts from a CSV file

```python
book = ContactBook()
book.add(Contact("Alice Murphy", "0851234567", "alice@example.com"))
book.add(Contact("Bob Kelly", "0877654321", "bob@example.com"))
book.list_all()
book.save("contacts.csv")

results = book.find("alice")
for c in results:
    print(c)
```

## Challenge 2 — Vending Machine

Build a `VendingMachine` class. All money is stored in **cent** as whole numbers (e.g. €1.20 is `120`). This avoids rounding errors such as `0.1 + 0.2` giving `0.30000000000000004`.

- A **class variable** `VALID_COINS = [10, 20, 50, 100, 200]`.
- `__init__` creates two **private dictionaries**, `_prices` (item → price in cent) and `_quantities` (item → number left), and sets `_credit = 0`.
- `add_item(name, price, quantity)` validates its inputs: the name is not blank, the price is positive, and the quantity is not negative.
- `insert_coin(coin)` raises `ValueError` if the coin is not in `VALID_COINS`. Otherwise it adds the coin to the credit.
- `credit` is a **read-only** property. The only way to add credit is to insert a coin.
- `buy(name)` raises `ValueError` if the item does not exist, is sold out, or costs more than the credit. Otherwise it reduces the quantity by 1, sets the credit back to 0 and **returns the change** in cent.
- `cancel()` returns the credit and sets it back to 0.
- `__str__` shows the credit in euro and lists each item with its price and stock.

```python
vm = VendingMachine()
vm.add_item("Crisps", 120, 5)
vm.add_item("Water", 150, 0)

vm.insert_coin(100)
vm.insert_coin(50)
print(vm)
print("Change:", vm.buy("Crisps"))     # Change: 30

for action in [lambda: vm.insert_coin(5),
               lambda: vm.buy("Water"),
               lambda: vm.buy("Chocolate")]:
    try:
        action()
    except ValueError as e:
        print(f"Error: {e}")
```

## Challenge 3 — Car Park

Build a `CarPark` class:

- `__init__(self, name, capacity, hourly_rate)`. `capacity` must be a positive whole number and is a **read-only** property. `hourly_rate` is a property with a setter, which must be positive, because the manager may change the price.
- A private list `_parked` holds the registrations of the cars that are parked, and `_takings` starts at 0.
- `enter(reg)` tidies the registration with `.strip().upper()`. Raise `ValueError` if it is blank, if the car park is full, or if that car is already parked.
- `leave(reg, hours)` raises `ValueError` if the car is not parked or `hours` is not positive. Part-hours are charged as a full hour (use `math.ceil`). It removes the car, adds the fee to the takings and **returns** the fee.
- Read-only computed properties: `spaces_free`, `is_full` and `takings`.
- `parked_cars()` returns a **copy** of the list (see Section 04, Example 2).
- `__str__`, e.g. `Tramore Car Park: 2/3 spaces used, takings €7.50`.

```python
cp = CarPark("Tramore Car Park", 3, 2.50)
for reg in ["261-W-123", "08-d-4567", "191-KK-88"]:
    cp.enter(reg)
print(cp, cp.is_full)               # ... 3/3 spaces used ... True

try:
    cp.enter("12-C-1")              # full, so ValueError
except ValueError as e:
    print(f"Error: {e}")

print("Fee:", cp.leave("08-D-4567", 2.5))   # 3 hours x €2.50 = 7.5
cp.enter("12-C-1")                          # now there is room

cars = cp.parked_cars()
cars.clear()                        # must NOT empty the car park
print(cp.parked_cars())
print(cp)
```
