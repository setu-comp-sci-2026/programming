# Lab 09
Classes and Objects (Part 2): Validation and Encapsulation

**Python skills:** validation in `__init__` · default parameters in methods · testing with `assert` · class variables · `_` and `__` · getters and setters · public interface · `@property` · read-only and computed properties

## Learning outcomes

By the end of this lab, you should be able to:

- Validate data in `__init__` so that every object is valid from the moment it is created.
- Test a class with simple `assert` statements, including checks that bad values are rejected.
- Distinguish **instance variables** from **class variables**.
- Explain why public attributes let outside code bypass a class's checks.
- Use the `_` convention, and explain what `__` (name mangling) does.
- Design a small **public interface**, and return copies rather than internal lists.
- Write getters and setters, and call setters from `__init__` so each check is written once.
- Convert getters and setters to `@property`, including read-only and computed properties.
