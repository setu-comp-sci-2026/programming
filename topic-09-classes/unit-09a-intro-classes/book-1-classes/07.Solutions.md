### 03 — BankAccount, first version
- Final balances: Alice **€625.00**, Bob **€1300.00**.
- Carol: `100 − 500 = −400`, then `−50` → `−450`, then withdrawing `−10` adds 10 → **€-440.00**.
- Rules: deposits must be positive; withdrawals must be positive; cannot withdraw more than the balance.
- The default parameter is `initial_balance=0` in `__init__`.
- In `alice_account.deposit(200)`, `self` is `alice_account`.

### 04 — Validation and history
- Without `try`, the traceback shows the call `acc.withdraw(2000)` in the main code **and** the `raise ValueError(...)` line inside `withdraw`.
- `BankAccount("ACC009", "Zed", -20)` → `ValueError: Initial balance cannot be negative`.
- The class **raises** rather than prints so the **caller** decides how to respond (show a message, ask again, log it). The class should not need to know whether it is used in a menu, a GUI or a test.
- `for t_type, amount, balance in ...` **unpacks** each 3-item tuple into three variables.
- `self.transactions` is created without a parameter.
- The `append` must come **after** the validation checks. A rejected withdrawal raises before reaching it, so it is never recorded.

Full Section 04 class with history (including the `description` extension from 9b Section 01):

```python
class BankAccount:
    def __init__(self, account_no, name, initial_balance=0):
        if initial_balance < 0:
            raise ValueError("Initial balance cannot be negative")
        self.account_no = account_no
        self.name = name
        self.balance = initial_balance
        self.transactions = []

    def deposit(self, amount, description="Deposit"):
        if amount <= 0:
            raise ValueError(f"Deposit amount must be positive, got {amount}")
        self.balance += amount
        self.transactions.append((description, amount, self.balance))
        print(f"Deposited €{amount:.2f}. New balance: €{self.balance:.2f}")

    def withdraw(self, amount, description="Withdrawal"):
        if amount <= 0:
            raise ValueError(f"Withdrawal amount must be positive, got {amount}")
        if amount > self.balance:
            raise ValueError(f"Insufficient funds. Balance: €{self.balance:.2f}")
        self.balance -= amount
        self.transactions.append((description, amount, self.balance))
        print(f"Withdrew €{amount:.2f}. New balance: €{self.balance:.2f}")

    def print_statement(self):
        print(f"Statement for {self.name} ({self.account_no})")
        print("-" * 45)
        for t_type, amount, balance in self.transactions:
            print(f"  {t_type:<12} €{amount:>8.2f}   Balance: €{balance:.2f}")

    def __str__(self):
        return f"Account {self.account_no} ({self.name}): €{self.balance:.2f}"
```

class Temperature:
    def __init__(self, celsius):
        self.celsius = celsius

    def to_fahrenheit(self):
        return self.celsius * 9 / 5 + 32

    def is_freezing(self):
        return self.celsius <= 0

    def __str__(self):
        return f"{self.celsius:.1f}°C ({self.to_fahrenheit():.1f}°F)"


for c in [-5, 0, 20, 100]:

# 20.0°C (68.0°F)

## Challenge 2
```python
class Student:
    def __init__(self, name, student_id):
        self.name = name
        self.student_id = student_id
        self.scores = []

    def add_score(self, score):
        if not 0 <= score <= 100:
            raise ValueError(f"Score must be 0-100, got {score}")
        self.scores.append(score)

    def average(self):
        if not self.scores:
            return 0
        return sum(self.scores) / len(self.scores)

    def highest(self):
        if not self.scores:
            return None
        return max(self.scores)

    def grade(self):
        avg = self.average()
        if avg >= 70:
            return "A"
        elif avg >= 60:
            return "B"
        elif avg >= 50:
            return "C"
        elif avg >= 40:
            return "D"
        return "F"

    def __str__(self):
        return f"[{self.student_id}] {self.name}: avg={self.average():.1f} grade={self.grade()}"


def test_student():
    s = Student("Alice", "S001")
    assert s.highest() is None
    for score in [72, 65, 58]:
        s.add_score(score)
    assert s.average() == 65.0
    assert s.grade() == "B"
    assert s.highest() == 72
    try:
        s.add_score(105)
        print("FAIL: 105 accepted")
    except ValueError:
        print("PASS: 105 rejected")
    print(s)   # [S001] Alice: avg=65.0 grade=B
    print("All tests passed!")


test_student()
```

## Challenge 3
Faults, in the order they appear when the program runs:

1. `def needs_heating():` is missing `self` → **`TypeError`** (*takes 0 positional arguments but 1 was given*). Fix: `def needs_heating(self):`.
2. `target = target` stores nothing on the object → **`AttributeError`** (*no attribute 'target'*) when `needs_heating` runs. Fix: `self.target = target`.
3. `self.current = degrees` replaces the temperature instead of adding to it → **logic error** (shows `2°C` instead of `20°C`). Fix: `self.current += degrees`.
4. `__str__` **prints** instead of returning → **`TypeError`** (*`__str__` returned non-string (type NoneType)*). Fix: `return f"..."`.

Students usually see fault 4 before fault 3, because the wrong `2°C` is printed just before the `TypeError`.

Corrected:
```python
class Thermostat:
    def __init__(self, room, target):
        self.room = room
        self.target = target
        self.current = 18

    def heat_up(self, degrees):
        self.current += degrees

    def needs_heating(self):
        return self.current < self.target

    def __str__(self):
        return f"{self.room}: {self.current}°C (target {self.target}°C)"


t = Thermostat("Kitchen", 21)
print(t.needs_heating())   # True
t.heat_up(2)
print(t)                   # Kitchen: 20°C (target 21°C)
```

```python
class DogDayCare:
    def __init__(self, name, capacity):
        self.name = name
        self.capacity = capacity
        self.dogs = []

    def check_in(self, dog):
        if len(self.dogs) >= self.capacity:
            raise ValueError(f"{self.name} is full")
        for d in self.dogs:
            if d.name == dog.name:
                raise ValueError(f"{dog.name} is already checked in")
        self.dogs.append(dog)

    def check_out(self, name):
        for d in self.dogs:
            if d.name == name:
                self.dogs.remove(d)
                return d
        raise ValueError(f"No dog called {name}")

    def average_age(self):
        if not self.dogs:
            return 0
        return sum(d.age for d in self.dogs) / len(self.dogs)

    def __str__(self):
        return f"{self.name}: {len(self.dogs)}/{self.capacity} dogs"


care = DogDayCare("Happy Paws", 3)
care.check_in(Dog("Buddy", 4, "Labrador"))
care.check_in(Dog("Luna", 2, "Collie"))
care.check_in(Dog("Max", 7, "Beagle"))
print(care)                       # Happy Paws: 3/3 dogs

rex = Dog("Rex", 5, "Terrier")
try:
    care.check_in(rex)
except ValueError as e:
    print("Error:", e)            # Error: Happy Paws is full

care.check_out("Luna")
care.check_in(rex)
print(care)                       # Happy Paws: 3/3 dogs
print(f"Average age: {care.average_age():.1f}")   # 5.3
```
If students haven't met generator expressions, `average_age` can use a loop with a running total. Returning the dog from `check_out` is optional but useful.
