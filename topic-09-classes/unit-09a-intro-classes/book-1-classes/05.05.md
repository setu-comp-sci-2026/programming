# Code from Class: More Methods and Validation in `__init__`

## Example 1 — Methods that call methods

Create `05_rectangle.py`:

```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

    def perimeter(self):
        return 2 * (self.width + self.height)

    def is_square(self):
        return self.width == self.height

    def scale(self, factor):
        """Return a NEW Rectangle scaled by factor."""
        return Rectangle(self.width * factor, self.height * factor)

    def __str__(self):
        return f"Rectangle({self.width} x {self.height})"


r = Rectangle(4, 6)
print(r)                              # Rectangle(4 x 6)
print(f"Area: {r.area()}")            # Area: 24
print(f"Perimeter: {r.perimeter()}")  # Perimeter: 20
print(f"Is square: {r.is_square()}")  # Is square: False

big = r.scale(3)
print(big)                            # Rectangle(12 x 18)
print(r)                              # Rectangle(4 x 6), unchanged
```

**Compare:** `Circle.scale()` in Section 02 **changed** the existing circle. `Rectangle.scale()` **returns a new** rectangle and leaves the original alone. Both approaches are valid. Choose one deliberately and say so in the docstring.

## Example 2 — Default parameters in methods

Methods can have default values, just like functions:

```python
    def deposit(self, amount, description="Deposit"):
```

## Example 3 — Validate as soon as data arrives

If `__init__` accepts bad data, every other method has to cope with it. It is better to reject it straight away.

Create `05_student_valid.py`:

```python
class Student:
    def __init__(self, name, student_id, gpa):
        if not name or not name.strip():
            raise ValueError("Name cannot be empty")
        self.name = name.strip()

        if not student_id.startswith("S"):
            raise ValueError("Student ID must start with 'S'")
        self.student_id = student_id

        if not 0.0 <= gpa <= 4.0:
            raise ValueError(f"GPA must be between 0.0 and 4.0, got {gpa}")
        self.gpa = gpa

    def __str__(self):
        return f"Student({self.student_id}: {self.name}, GPA={self.gpa:.2f})"
```

## Example 4 — The caller handles the exception

```python
test_data = [
    ("Alice", "S001", 5.0),
    ("", "S002", 3.5),
    ("Carl", "X003", 2.9),
    ("  Bob  ", "S004", 3.8),
]

for name, sid, gpa in test_data:
    try:
        s = Student(name, sid, gpa)
        print("Created:", s)
    except ValueError as e:
        print(f"Cannot create student: {e}")
```

**Predict:** Which of the four will be created? What will Bob's name look like?

**Remember:** If `__init__` raises an exception, **no object is created**. The variable `s` is not assigned.
