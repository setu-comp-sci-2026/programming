# Week 9 Lab — Classes and Objects (Part 1)

**Python skills:** classes · objects · `__init__` · `self` · instance variables · methods · `__str__` · validation · `ValueError` · testing with `assert` · class variables

## Learning outcomes

By the end of this lab, you should be able to:

- Explain the difference between a **class** (the blueprint) and an **object** (an instance).
- Define a class with an `__init__` method and instance variables.
- Explain what `self` refers to and why every method needs it.
- Write instance methods that read and change an object's state.
- Add a `__str__` method so that `print()` displays an object in a readable way.
- Design a `BankAccount` class by identifying its **attributes** and **methods**.
- Validate data in `__init__` and in methods, raising `ValueError` for bad values.
- Test a class with simple `assert` statements.
- Distinguish **instance variables** from **class variables**.

## Before you begin

You should already be comfortable with functions, lists, dictionaries, loops and `try` / `except` (Week 8).

Create a new folder called **week09a** and save each file from this lab in it.

**This week's boundary:** we access attributes directly (e.g. `acc.balance`). Protecting attributes with a leading underscore and using `@property` is covered in the next part (9b — Encapsulation).
