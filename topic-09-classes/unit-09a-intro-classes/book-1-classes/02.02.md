# Code from Class: Methods and `__str__`

An **instance method** is a function defined inside a class. Its first parameter is always `self`, so it can read and change the object's own data.

## Example 1 — A Circle with methods

Create `02_circle.py`:

```python
class Circle:
    def __init__(self, radius):
        self.radius = radius

    def area(self):
        """Return the area of the circle."""
        return 3.14159 * self.radius ** 2

    def circumference(self):
        """Return the circumference of the circle."""
        return 2 * 3.14159 * self.radius

    def scale(self, factor):
        """Make the circle bigger or smaller."""
        self.radius *= factor


c = Circle(5)
print(f"Area: {c.area():.2f}")                     # Area: 78.54
print(f"Circumference: {c.circumference():.2f}")   # Circumference: 31.42

c.scale(2)
print(f"After scaling, radius = {c.radius}")       # After scaling, radius = 10
```

Notice the two kinds of method:

| Method | Returns a value? | Changes the object? |
|---|---|---|
| `area()` | Yes | No |
| `circumference()` | Yes | No |
| `scale(factor)` | No | Yes, it changes `self.radius` |

**Try it:** Call `c.area()` again after scaling. Why has it changed when you did not change `area()`?

## Example 2 — Printing an object

Add this line to the bottom of `02_circle.py`:

```python
print(c)
```

You will see something like `<__main__.Circle object at 0x10b3c2d90>`. That's not much use! Add a `__str__` method **inside** the class:

```python
    def __str__(self):
        return f"Circle(radius={self.radius})"
```

Run it again. `print(c)` now shows `Circle(radius=10)`.

**Remember:** `__str__` must **return** a string. It should not `print`. Python's `print()` calls `__str__` for you.

## Example 3 — A complete Student class

Create `02_student.py`:

```python
class Student:
    """Represents a student with a name, ID and list of scores."""

    def __init__(self, name, student_id):
        self.name = name
        self.student_id = student_id
        self.scores = []                # every student starts with no scores

    def add_score(self, score):
        self.scores.append(score)

    def average(self):
        if not self.scores:
            return 0
        return sum(self.scores) / len(self.scores)

    def is_passing(self, threshold=40):
        return self.average() >= threshold

    def __str__(self):
        status = "Pass" if self.is_passing() else "Fail"
        return f"[{self.student_id}] {self.name}: avg={self.average():.1f} ({status})"


s = Student("Alice", "S001")
s.add_score(85)
s.add_score(92)
s.add_score(78)
print(s)    # [S001] Alice: avg=85.0 (Pass)
```

Points to notice:

- `self.scores = []` is created in `__init__` even though it is **not** a parameter. An attribute can start with a fixed value.
- `is_passing()` calls another method using `self.average()`.
- `__str__` calls **both** `self.is_passing()` and `self.average()`.

**Try it:** Create a second student, `S002` Bob, with scores `30`, `45` and `25`. Predict what `print()` will show, then run it.
