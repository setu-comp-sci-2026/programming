# Code from Class: BankAccount with Validation and History

The object should **protect its own data**. If a method receives a bad value, it refuses by raising a `ValueError`. The **calling code** decides what to tell the user, using the `try` / `except` you learned in Week 8.

## Step 1 — Add validation

Create `04_bank_account_v2.py`:

```python
class BankAccount:
    """A bank account that rejects invalid transactions."""

    def __init__(self, account_no, name, initial_balance=0):
        if initial_balance < 0:
            raise ValueError("Initial balance cannot be negative")
        self.account_no = account_no
        self.name = name
        self.balance = initial_balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError(f"Deposit amount must be positive, got {amount}")
        self.balance += amount
        print(f"Deposited €{amount:.2f}. New balance: €{self.balance:.2f}")

    def withdraw(self, amount):
        if amount <= 0:
            raise ValueError(f"Withdrawal amount must be positive, got {amount}")
        if amount > self.balance:
            raise ValueError(f"Insufficient funds. Balance: €{self.balance:.2f}")
        self.balance -= amount
        print(f"Withdrew €{amount:.2f}. New balance: €{self.balance:.2f}")

    def __str__(self):
        return f"Account {self.account_no} ({self.name}): €{self.balance:.2f}"
```

Notice that the checks happen **before** the balance changes. If a check fails, the balance is untouched.

## Step 2 — Use it safely

```python
acc = BankAccount("ACC001", "Alice", 1000)
acc.deposit(500)
acc.withdraw(200)

try:
    acc.withdraw(2000)
except ValueError as e:
    print(f"Error: {e}")

try:
    acc.deposit(-50)
except ValueError as e:
    print(f"Error: {e}")

print(acc)    # Account ACC001 (Alice): €1300.00
```

## Step 3 — Keep a transaction history

An attribute can hold a **list**. Change your class so that:

1. `__init__` has an extra line: `self.transactions = []`
2. `deposit` appends a tuple after updating the balance:

    ```python
    self.transactions.append(("Deposit", amount, self.balance))
    ```

3. `withdraw` appends `("Withdrawal", amount, self.balance)` in the same way.
4. A new method prints a statement:

    ```python
    def print_statement(self):
        print(f"Statement for {self.name} ({self.account_no})")
        print("-" * 45)
        for t_type, amount, balance in self.transactions:
            print(f"  {t_type:<12} €{amount:>8.2f}   Balance: €{balance:.2f}")
    ```

Test it:

```python
acc = BankAccount("ACC010", "Dara", 100)
acc.deposit(250)
acc.withdraw(80)
acc.deposit(30)
acc.print_statement()
```

Expected output (after the "Deposited…/Withdrew…" messages):

```text
Statement for Dara (ACC010)
---------------------------------------------
  Deposit      €  250.00   Balance: €350.00
  Withdrawal   €   80.00   Balance: €270.00
  Deposit      €   30.00   Balance: €300.00
```
