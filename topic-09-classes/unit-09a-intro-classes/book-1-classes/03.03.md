# Code from Class: BankAccount, First Version

Before we write any code, we **design** the class. Ask two questions:

| Question | BankAccount answer | Becomes… |
|---|---|---|
| What does it **know**? (state) | account number, holder's name, balance | **attributes** in `__init__` |
| What can it **do**? (behaviour) | deposit, withdraw, report balance, display itself | **methods** |

This is **object-oriented design**.

## Step 1 — Write the class

Create `03_bank_account.py`:

```python
class BankAccount:
    """A simple bank account."""

    def __init__(self, account_no, name, initial_balance=0):
        self.account_no = account_no
        self.name = name
        self.balance = initial_balance

    def deposit(self, amount):
        self.balance += amount

    def withdraw(self, amount):
        self.balance -= amount

    def get_balance(self):
        return self.balance

    def __str__(self):
        return f"Account {self.account_no} ({self.name}): €{self.balance:.2f}"
```

`initial_balance=0` is a **default parameter**, just as in Week 3. If we leave it out, the account opens with €0.

## Step 2 — Create and use two accounts

Add underneath the class:

```python
alice_account = BankAccount("ACC001", "Alice Murphy", 500)
bob_account = BankAccount("ACC002", "Bob Kelly")

print(alice_account)    # Account ACC001 (Alice Murphy): €500.00
print(bob_account)      # Account ACC002 (Bob Kelly): €0.00

alice_account.deposit(200)
alice_account.withdraw(75)

bob_account.deposit(1000)
bob_account.deposit(500)
bob_account.withdraw(200)

print(alice_account)
print(bob_account)
print(f"Alice's balance: €{alice_account.get_balance():.2f}")
```

## Step 3 — Break it on purpose

Add this to the bottom of the file:

```python
carol = BankAccount("ACC003", "Carol", 100)
carol.withdraw(500)      # more than she has
carol.deposit(-50)       # a negative deposit?
carol.withdraw(-10)      # a negative withdrawal ADDS money!
print(carol)
```

**Record:** What balance is printed? Python ran every line without complaint. These are **logic errors** (Week 8): the program runs but gives a wrong answer.
