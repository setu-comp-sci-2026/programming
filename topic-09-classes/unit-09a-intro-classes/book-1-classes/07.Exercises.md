## Exercise 1 — Book

Create `ex1_book.py`. Write a `Book` class with:

- instance variables `title`, `author` and `pages`;
- a method `is_long()` that returns `True` if the book has **more than 300** pages;
- a `__str__` that returns, e.g. `'Dubliners' by James Joyce (152 pages)`.

Test with:

```python
b1 = Book("Dubliners", "James Joyce", 152)
b2 = Book("Ulysses", "James Joyce", 730)
print(b1)
print(b2)
print(b1.is_long(), b2.is_long())   # False True
```

## Exercise 2 — Dog Day Care, the OOP way

Create `ex2_dog.py`. In earlier weeks each dog was a dictionary such as `{"name": "Buddy", "age": 4}`. Write a `Dog` class with:

## Exercise 3 — Temperature

Create `ex3_temperature.py`. Write a `Temperature` class that stores a value in `celsius`. Add:

- `to_fahrenheit()`, which returns `celsius * 9 / 5 + 32`;
- `is_freezing()`, which returns `True` if the temperature is at or below 0 °C;
- `__str__` returning, e.g. `20.0°C (68.0°F)`. Your `__str__` should **call** `self.to_fahrenheit()`.

Test with `-5`, `0`, `20` and `100`.

## Exercise 4 — Product with validation

Create `ex4_product.py`. Write a `Product` class for a small shop:

- `__init__(self, name, price, quantity=0)`:
    - raise `ValueError` if `name` is blank;
    - raise `ValueError` if `price` is not greater than 0;
    - raise `ValueError` if `quantity` is negative.
- `restock(amount)` adds stock (`amount` must be positive).
- `sell(amount)` removes stock. Raise `ValueError` if `amount` is not positive or is **more than** the stock available.
- `stock_value()` returns `price * quantity`.
- `__str__` returning, e.g. `Kettle: €24.99 x 10 (value €249.90)`.

In your main code, create a kettle priced €24.99 with 10 in stock. Sell 3, restock 5, then try to sell 50 inside a `try` / `except`. Print the product after each step.

## Exercise 5 — Test your Product
