# Code from Class: Your First Class

So far we have stored data in variables and dictionaries, and written separate functions to work on that data. **Object-oriented programming (OOP)** bundles the data (*state*) and the functions (*behaviour*) together into **objects**.

- A **class** is the blueprint. You define it once.
- An **object** (or *instance*) is one specific thing built from the blueprint. You can create as many as you like.

## Example 1 — An empty class

Create `01_person.py`:

```python
class Dog:
    pass

rex = Dog()
buddy = Dog()

print(type(rex))      # <class '__main__.Dog'>
print(rex is buddy)   # False
```

`pass` means "nothing here yet". Even an empty class can create objects.

**Think:** `rex` and `buddy` were made from the same class. Why does `rex is buddy` print `False`?

## Example 2 — `__init__` and `self`

Replace the code in `01_person.py` with:

```python
class Person:
    def __init__(self, name, age):
        self.name = name    # instance variable
        self.age = age      # instance variable


alice = Person("Alice", 25)
bob = Person("Bob", 30)

print(alice.name)   # Alice
print(bob.age)      # 30
```

Key points:

- `__init__` is the **constructor**. Python calls it automatically when you write `Person("Alice", 25)`.
- `self` is the object being created. `self.name = name` stores the value **on that object**.
- We pass two arguments (`"Alice"`, `25`), but `__init__` has three parameters. Python fills in `self` for you.
- Class names use `PascalCase`: `Person`, `BankAccount`, `DogDayCare`.

## Example 3 — Each object has its own data

Add to the bottom of `01_person.py`:

```python
alice.age = 26
print(alice.age)   # 26
print(bob.age)     # 30 (unchanged)
```

## Example 4 — Compare with a dictionary

In earlier weeks we would have written:

```python
alice_dict = {"name": "Alice", "age": 25}
print(alice_dict["name"])
```

With a class we write `alice.name` instead of `alice_dict["name"]`. The real benefit appears in the next section, when we add **methods** that belong to the object.
