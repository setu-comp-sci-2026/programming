# Code from Class: Testing Classes and Class Variables

## Part A — Test your class with `assert`

`assert condition, "message"` does nothing if the condition is `True`, and raises `AssertionError` with the message if it is `False`. It is a quick way to check that a class behaves as expected.

Create `06_test_bank.py`. Copy your **validated** `BankAccount` class from Section 04 to the top of the file, then add:

```python
def test_bank_account():
    print("Testing BankAccount...")

    # Test 1: create account
    acc = BankAccount("ACC001", "Alice", 1000)
    assert acc.balance == 1000, "Initial balance wrong"
    print("  PASS: Initial balance")

    # Test 2: deposit
    acc.deposit(500)
    assert acc.balance == 1500, "Deposit failed"
    print("  PASS: Deposit")

    # Test 3: withdraw
    acc.withdraw(200)
    assert acc.balance == 1300, "Withdraw failed"
    print("  PASS: Withdraw")

    # Test 4: overdraft rejected
    try:
        acc.withdraw(99999)
        print("  FAIL: Should have raised ValueError")
    except ValueError:
        print("  PASS: Overdraft rejected")

    print("All tests passed!")


test_bank_account()
```

**Try it — break the class on purpose:** In `withdraw`, change `self.balance -= amount` to `self.balance += amount`. Run the tests. Which test fails and what message do you see? Fix it again.

**Try it — add tests:** Add two more tests:

- Test 5: a negative deposit is rejected.
- Test 6: a rejected withdrawal leaves the balance **unchanged** (still `1300`).

**Think:** Test 4 uses `try` / `except` rather than `assert`. Why?

## Part B — Class variables

So far every variable has been an **instance variable** (`self.something`). Each object has its own copy.

A **class variable** is defined in the class body, outside any method. **All** objects share it.

Create `06_class_vars.py`:

```python
class BankAccount:
    interest_rate = 0.02    # class variable, shared by all accounts
    account_count = 0       # how many accounts have been created

    def __init__(self, name, balance=0):
        self.name = name            # instance variable
        self.balance = balance      # instance variable
        BankAccount.account_count += 1

    def apply_interest(self):
        interest = self.balance * BankAccount.interest_rate
        self.balance += interest
        return interest


acc1 = BankAccount("Alice", 1000)
acc2 = BankAccount("Bob", 2000)
acc3 = BankAccount("Carol", 1500)

print(f"Total accounts: {BankAccount.account_count}")      # 3
print(f"Alice interest: €{acc1.apply_interest():.2f}")     # €20.00

BankAccount.interest_rate = 0.03     # changes the rate for EVERY account
print(f"Bob interest: €{acc2.apply_interest():.2f}")       # €60.00
```

| | Instance variable | Class variable |
|---|---|---|
| Where created | inside `__init__`, using `self.` | class body, outside methods |
| Accessed as | `acc1.balance` | `BankAccount.interest_rate` |
| One copy per… | object | class |
| Example | `name`, `balance` | `interest_rate`, `account_count` |
