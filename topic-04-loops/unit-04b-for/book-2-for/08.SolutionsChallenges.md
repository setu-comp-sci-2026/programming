# Challenge Solutions

## Challenge 1 – Password Strength Checker

```python
password = input("Enter a password: ")

uppercase = 0
lowercase = 0
digits = 0

for character in password:
    if character.isupper():
        uppercase = uppercase + 1
    elif character.islower():
        lowercase = lowercase + 1
    elif character.isdigit():
        digits = digits + 1

print("Uppercase letters:", uppercase)
print("Lowercase letters:", lowercase)
print("Digits:", digits)
```

## Challenge 2 – Word Counter

Using the lab hint **Words = Spaces + 1**:

```python
sentence = input("Enter a sentence: ")
spaces = 0

for character in sentence:
    if character == " ":
        spaces = spaces + 1

words = spaces + 1
print("Words:", words)
```

This assumes one space between words and no spaces at the beginning or end.

## Challenge 3 – Times Table Generator

```python
number = int(input("Enter a number: "))

for multiplier in range(1, 13):
    answer = number * multiplier
    print(number, "x", multiplier, "=", answer)
```

## Challenge 4 – Character Frequency

```python
sentence = input("Enter a sentence: ")
search_character = input("Enter a character to search for: ")

count = 0

for character in sentence:
    if character == search_character:
        count = count + 1

print(search_character, "appears", count, "times.")
```

### Optional improvement – ignore case

```python
sentence = input("Enter a sentence: ")
search_character = input("Enter a character to search for: ")

count = 0

for character in sentence:
    if character.lower() == search_character.lower():
        count = count + 1

print(search_character, "appears", count, "times.")
```
