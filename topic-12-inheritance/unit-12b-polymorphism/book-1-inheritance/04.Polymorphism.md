# Step 4 — Polymorphic Behaviour

## 4.1 — Mixed list of accounts

```python
from bank_account import BankAccount
from savings_account import SavingsAccount
from current_account import CurrentAccount
from fixed_term_account import FixedTermAccount

accounts = [
    SavingsAccount("S001", "Alice", 1000, 0.03),
    CurrentAccount("C001", "Bob", -200),
    FixedTermAccount("F001", "Carol", 5000, 0.04, 12),
]

# Polymorphic loop — each prints via its own __str__
for acc in accounts:
    print(acc)
```

## 4.2 — Using `isinstance()`

```python
for acc in accounts:
    print(f"\n{acc.get_owner()}:")
    if isinstance(acc, FixedTermAccount):
        print(f"  Fixed term: {acc.get_term_months()} months")
    elif isinstance(acc, SavingsAccount):
        print(f"  Interest rate: {acc.get_interest_rate():.1%}")
    elif isinstance(acc, CurrentAccount):
        print(f"  Overdraft limit: €{acc.get_overdraft_limit():.0f}")
```

**Think:** Why must the `FixedTermAccount` check come *before* the `SavingsAccount` check? Swap them and see.

## 4.3 — Count by type

```python
savings_count = sum(1 for a in accounts
                    if isinstance(a, SavingsAccount))
current_count = sum(1 for a in accounts
                    if isinstance(a, CurrentAccount))
print(f"Savings: {savings_count}, Current: {current_count}")
# Savings: 2, Current: 1   ← the fixed-term account counts as savings too
```

## 4.4 — One method, different behaviour: `monthly_update()`

Instead of asking each object what type it is, let each class decide what to do at month end.

Add to `BankAccount`:
```python
def monthly_update(self) -> None:
    pass                     # plain accounts: nothing to do
```

Override in `SavingsAccount`:
```python
def monthly_update(self) -> None:
    self.deposit(self._balance * self._interest_rate / 12)   # 1 month's interest
```

Override in `CurrentAccount`:
```python
def monthly_update(self) -> None:
    if self._balance < 0:
        self._balance -= 5.00                   # overdraft fee
```

Test:
```python
for acc in accounts:
    acc.monthly_update()     # no isinstance needed!
    print(acc)
# SavingsAccount S001 (Alice): €1002.50 @ 3.0%
# CurrentAccount C001 (Bob): €-205.00 (overdraft €500)
# SavingsAccount F001 (Carol): €5016.67 @ 4.0% [fixed 12 months]
```

**Think:** `FixedTermAccount` has no `monthly_update()`. Why does Carol still get interest?

## 4.5 — `__eq__` for BankAccount

Two account objects are the same account if they have the same account number. Add to `BankAccount`:
```python
def __eq__(self, other) -> bool:
    if not isinstance(other, BankAccount):
        return NotImplemented
    return self._account_no == other._account_no

# Test
a1 = SavingsAccount("X100", "Alice", 50)
a2 = CurrentAccount("X100", "Alice", 50)
print(a1 == a2)   # True — same account number
```
