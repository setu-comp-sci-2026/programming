# Challenges

## Challenge 1 — Full Bank System

Build a bank account system:
- `BankAccount` base class with account_no, owner, balance and a list of transactions
- `SavingsAccount(BankAccount)` with interest rate and a limit of 3 withdrawals per month
- `CurrentAccount(BankAccount)` with overdraft limit and a €5 fee each month it is overdrawn
- `FixedTermAccount(SavingsAccount)` with term in months and no withdrawals until the term ends

Add a `Bank` class (like Shop) that manages a list of `BankAccount` objects with add, find, remove, and display methods. Add a `month_end()` method that calls `monthly_update()` on every account, and a `total_deposits()` method that returns the sum of all balances.

## Challenge 2 — Zoo System

Create a zoo management system:
- `Animal` base class with name, species, age
- `Mammal(Animal)` with fur colour
- `Bird(Animal)` with wingspan
- `Reptile(Animal)` with is_venomous

Store all in a `Zoo` class list. Display sorted by species. Filter by type using `isinstance`.

## Challenge 3 — Payroll Calculator

Create an employee payroll system:
- `Employee` base class with name, employee_id
- `SalariedEmployee(Employee)` with annual_salary
- `HourlyEmployee(Employee)` with hourly_rate, hours_per_week
- `CommissionEmployee(Employee)` with base_salary, sales, commission_rate

Each must implement `weekly_pay() -> float`. Use polymorphism to calculate total payroll from a mixed list.
