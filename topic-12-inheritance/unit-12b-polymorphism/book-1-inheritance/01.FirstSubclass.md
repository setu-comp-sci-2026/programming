# Step 1 — Creating Your First Subclass

## 1.1 — The `BankAccount` parent class

You built a `BankAccount` in the classes topic. Here is a tidy version to inherit from. Create `bank_account.py`:

```python
class BankAccount:
    def __init__(self, account_no: str, owner: str, balance: float = 0):
        self._account_no = account_no
        self._owner = owner
        self._balance = balance

    def get_account_no(self) -> str:
        return self._account_no

    def get_owner(self) -> str:
        return self._owner

    def get_balance(self) -> float:
        return self._balance

    def deposit(self, amount: float) -> None:
        if amount <= 0:
            raise ValueError("Deposit must be positive")
        self._balance += amount

    def withdraw(self, amount: float) -> None:
        if amount <= 0:
            raise ValueError("Withdrawal must be positive")
        if amount > self._balance:
            raise ValueError("Insufficient funds")
        self._balance -= amount

    def __str__(self) -> str:
        return f"BankAccount {self._account_no} ({self._owner}): €{self._balance:.2f}"
```

**Note:** the attributes use a *single* underscore (`_balance`), not a double one (`__balance`). Subclasses will need to change the balance, and a double underscore would hide it from them (name mangling turns `self.__balance` into `_BankAccount__balance`).

## 1.2 — A simple subclass

Create `savings_account.py`:

```python
from bank_account import BankAccount

class SavingsAccount(BankAccount):
    pass   # inherits everything for now

s = SavingsAccount("S001", "Alice", 100)
s.deposit(50)
print(s.get_owner())     # Alice
print(s.get_balance())   # 150
print(s)                 # BankAccount S001 (Alice): €150.00
```

**Think:** `SavingsAccount` has no code at all. Where do `deposit`, `get_owner` and `__str__` come from?

## 1.3 — Add a savings-specific attribute

Replace the `pass` version with:

```python
class SavingsAccount(BankAccount):
    def __init__(self, account_no: str, owner: str,
                 balance: float = 0, interest_rate: float = 0.02):
        super().__init__(account_no, owner, balance)
        self._interest_rate = interest_rate

    def get_interest_rate(self) -> float:
        return self._interest_rate

    def add_interest(self) -> None:
        self.deposit(self._balance * self._interest_rate)

    def __str__(self) -> str:
        return (f"SavingsAccount {self._account_no} ({self._owner}): "
                f"€{self._balance:.2f} @ {self._interest_rate:.1%}")
```

Test:

```python
s = SavingsAccount("S001", "Alice", 1000, 0.03)
s.add_interest()
print(s)    # SavingsAccount S001 (Alice): €1030.00 @ 3.0%
```

**Try it:** Change the subclass to use `self.__interest_rate` everywhere. Does it still work? Now try changing `BankAccount` to use `self.__balance`. What breaks, and why?
