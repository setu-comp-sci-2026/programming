# Step 3 — Using super()

## 3.1 — Extending a parent method

Add a `describe()` method to `BankAccount`:

```python
def describe(self) -> str:
    return f"{self._account_no} ({self._owner}): €{self._balance:.2f}"
```

Then *extend* it in `SavingsAccount`:

```python
def describe(self) -> str:
    base = super().describe()   # "S001 (Alice): €1000.00"
    return f"{base}, Interest: {self._interest_rate:.1%}"
```

Test:

```python
s = SavingsAccount("S001", "Alice", 1000, 0.03)
print(s.describe())   # S001 (Alice): €1000.00, Interest: 3.0%
```

## 3.2 — Multi-level inheritance

A fixed-term account is a savings account that you cannot withdraw from until the term ends.

Create `fixed_term_account.py`:

```python
from savings_account import SavingsAccount

class FixedTermAccount(SavingsAccount):
    def __init__(self, account_no: str, owner: str, balance: float,
                 interest_rate: float, term_months: int):
        super().__init__(account_no, owner, balance, interest_rate)
        self._term_months = term_months

    def get_term_months(self) -> int:
        return self._term_months

    def withdraw(self, amount: float) -> None:      # overrides parent
        raise ValueError("No withdrawals until the term ends")

    def __str__(self) -> str:
        return f"{super().__str__()} [fixed {self._term_months} months]"
```

Test:

```python
f = FixedTermAccount("F001", "Carol", 5000, 0.04, 12)
print(f)
# SavingsAccount F001 (Carol): €5000.00 @ 4.0% [fixed 12 months]

f.add_interest()          # inherited from SavingsAccount
print(f.get_balance())    # 5200.0

try:
    f.withdraw(100)
except ValueError as e:
    print(f"Error: {e}")  # Error: No withdrawals until the term ends
```
