## Challenge 1a

**Note:** This challenge introduces the import statement. The functions we have used so far are available to us without importing them (e.g. `print()`).
If we need to use a function that is not available by default, we need to import it. We do this by firstly writing `import module_name` at the top of the file, then we can use the function by writing `module_name.function_name()`.

How do we know what functions are available? For this module, we will introduce the module names to you if you need them. As you get more familiar with Python, you will learn how to find out what functions are available. Open REPL by typing 'python3' (or 'python') in the command line and then type 

~~~
help() random
~~~

This will show you a URL to get documentation for the `random` module, which is a module that contains all the functions available in the `random` module. You can read more about the `random` module [here](https://docs.python.org/3/library/random.html).

Have a look at the documentation for the `random` module to find out what functions are available for us to use.

## Challenge 1b

Build a simple number-guessing game using functions.  Break the program into at least three functions:

- `get_secret_number()` — generates and returns a random integer between 1 and 100 (use `import random` and `random.randint(1, 100)`)
- `get_guess()` — prompts the user for a guess and returns it as an integer
- `check_guess(secret, guess)` — prints "Too high", "Too low", or "Correct!" and returns `True` if the guess is correct, `False` otherwise

The main program should keep asking for guesses until the user gets it right and should count how many attempts it took.

Example run:

~~~
Guess the number (1-100): 50
Too high
Guess the number (1-100): 25
Too low
Guess the number (1-100): 37
Correct! You got it in 3 attempts.
~~~

- `circle_area(radius)` — returns π × radius²
- `circle_circumference(radius)` — returns 2 × π × radius
