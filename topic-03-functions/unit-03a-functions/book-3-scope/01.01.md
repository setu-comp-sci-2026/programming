# A Note About These Labs

These labs contain **exercises** and **challenges** to help you practise
what you are learning.

**You are not expected to complete everything.** The aim is to
understand the concepts and become comfortable writing Python --- not to
race through every exercise.

##  Exercises

When you are learning something new, **write the code yourself** for the
first few exercises. Typing the code helps you become familiar with the
syntax and understand how it works.

If there are lots of similar exercises, you don't need to type
everything from scratch every time. Once you are confident that you
understand the syntax, it's perfectly OK to **copy and paste your
previous code and modify it** for the next exercise.

The important thing is that you understand the code you are writing.

> 💡 **Don't measure your progress by how many exercises you complete.
> Measure it by how much you understand.**

## Challenges

Challenges are **optional**.

Attempt them if:

-   you have completed the main exercises and have time left;
-   you have programmed before and would like something more
    challenging; or
-   you simply want some extra practice.

If you are still working through the main exercises, **don't worry about
the challenges**. Focus on understanding the core material first.

## Remember

Everyone comes to programming with different levels of experience and
everyone works at a different pace.

Take your time, experiment with the code, make mistakes, fix them, and
ask questions.

**You don't need to finish everything --- you need to understand what
you do.**
