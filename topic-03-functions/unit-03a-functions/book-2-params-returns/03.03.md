# Default Parameter Values

A *default value* makes a parameter optional — if the caller doesn't supply it, the default is used instead.

Create a new Python file and try the following:

~~~python
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Alice")                        # uses default: Hello, Alice!
greet("Bob", "Hi")                    # overrides default: Hi, Bob!
greet("Carol", greeting="Good morning")   # keyword override: Good morning, Carol!
~~~

Run it and confirm all three outputs.

## Rules for Default Values

Default parameters must come *after* all non-default parameters in the `def` line.  Try putting the default parameter first and observe the `SyntaxError`:

~~~python
def greet(greeting="Hello", name):   # SyntaxError
    print(f"{greeting}, {name}!")
~~~

## A Practical Example

Default values are useful when most callers want the same behaviour but you still want flexibility:

~~~python
def draw_line(char="-", width=30):
    """Print a horizontal line."""
    print(char * width)

draw_line()                  # ------------------------------
draw_line("=")               # ==============================
draw_line("*", 20)           # ********************
draw_line(width=10, char="+")# ++++++++++
~~~

Run each call and confirm the output matches the comments.
